`YunFengJingJingTi-Regular.ttf` is present for local development and visual evaluation only.

- Font: 云峰晶晶体 / YunFengJingJingTi-Regular
- Source page: https://www.dowebok.com/16240.html
- Download page: https://www.dowebok.com/down?id=16240
- Author / foundry: 云峰字库
- Retrieved: 2026-08-19
- SHA-256: `f29a1a406d542b4911a57a913dc1ddfc27e3f39e81560ed8ba88db00672c7d8a`

The Vite development server exposes this file at `/dev-fonts/YunFengJingJingTi-Regular.ttf` for the journal font picker. The production build does not copy or bundle it. Do not publish or redistribute it with a release build. Public descriptions of the font have conflicting commercial-use wording and report restrictions on embedding in software or apps; obtain written permission from 云峰字库 before any release or software embedding.

The open-licensed Xuandong Kaishu font is stored separately at `public/fonts/Xuandong-Kaishu.ttf`; it is already a production asset used by the notebook nameplate and is also available to the journal font picker.
