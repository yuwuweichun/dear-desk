V1 · REJECTED

Warm Studio

浅冷灰绿背景、浅粉米木桌与浅灰绿桌垫。用户已明确否决，禁止默认恢复。

已记录问题：粉灰扁平、婴儿薄荷关系和塑料感。

V2 · REJECTED / RUNTIME FALLBACK

冷灰胡桃木 + 蓝灰

中深胡桃木增加承载重量，蓝灰桌垫降低与墨绿本子的同色相竞争。

观察重点：判断整体是否仍偏灰、是否缺少个性。

V3 · REJECTED

海军蓝 + 蜂蜜木

扩大冷暖对比，用蜂蜜木和海军蓝建立清晰工作区。

观察重点：蜂蜜木是否过亮、蓝色是否偏办公。

V4 · REJECTED

陶土酒红 + 烟熏木

用低彩度红色与墨绿本子形成互补关系。

观察重点：粉红倾向是否过强，珊瑚部件是否与桌垫黏连。

V5 · REJECTED

石墨灰 + 焦糖木

以无彩石墨桌垫承托本子，让焦糖木提供温度。

观察重点：整体是否过于理性、像办公用品。

V6 · REJECTED

灰紫 + 深核桃木

尝试比蓝灰更柔和、比粉色更克制的情绪。

观察重点：灰紫与墨绿是否显脏、背景是否过粉。

V7 · REJECTED

赭黄 + 黑胡桃木

更温暖、偏手作与纸品的工作面。

观察重点：赭黄工作面是否面积过大并抢走焦点。

V8 · REJECTED

丹宁蓝 + 浅烟橡木

强调更日常的家居与布料感。

观察重点：浅木在暖光下是否再次接近 V1 的粉米感。

V9 · REJECTED

砖红 + 深橡木

用更直接的暖色与墨绿本子形成互补对比。

观察重点：桌垫是否喧闹，暖色面积是否改变产品性格。

V10 · REJECTED

黑白中性 + 古铜木

压低环境色彩，让本子靠绿色色相辨识。

观察重点：桌垫与本子明度是否过近，整体是否沉闷。

13 · DECISION

V1-V10 全部不通过

用户已否决十版，并提出模型造型本身可能是主要问题。下一步不再盲目生成整套候选，而是通过开放实时调色器分别控制表面，用实验结果判断配色与模型各自的影响。

后续边界

本页继续作为负向约束保存。任何新方案必须使用新编号，不能覆盖这里的色值、截图和否决状态。

15 · GLOSSARY

上下文术语表

角色色

按背景、承载面、工作面等职责分配的基础色。

在本任务：六个可变角色是背景、木桌三色和桌垫两色。

PBR

用粗糙度、凹凸、环境遮蔽和反射描述表面对光线的响应。

在本任务：V2-V10 固定同一套 PBR。
