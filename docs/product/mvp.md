## 1. 产品定位

Dear Desk 不是一个以 3D 画面为卖点的日记工具，而是一个会随着使用逐渐留下痕迹的私人工作台。

它的首版目标是验证用户是否愿意反复回到同一张桌子，并对自己积累的空间状态产生记忆和珍惜。Three.js 服务于空间记忆、物体手感和时间沉积，不单独作为展示效果存在。

## 2. 目标用户行为

用户可以在三分钟内完成一次轻量记录：

```text
坐下 -> 打开本子留下文字，或独立制作一张贴纸 -> 放在桌面或日记 -> 离开
```

用户不必每天写长文。一次有效记录可以只是一句话、一张照片或一个当天关键词。

## 3. 首版要验证的问题

1. 用户是否愿意连续七天回到工作台。
2. 用户是否开始记住某件内容被放在什么位置。
3. 用户是否因为已有痕迹而不愿意重置桌面。

第三个问题是首版最重要的产品信号。它代表桌面开始形成普通日记工具缺少的情感壁垒。

## 4. 建议首版范围

### 4.1 一张可持续保存的桌面

- 桌面具有稳定视角和有限的可放置区域。
- 用户摆放的内容在重新打开页面后仍然存在。
- 当前默认视觉采用“明亮轻拟物 Animal Desk”材质版本 `V2.0`：场景使用冷灰背景，程序化中深胡桃木桌为暖纸工坊风格的三抽屉书写桌，包含一块厚圆角台面、窄—宽—窄抽屉带、三枚暗金黄铜旋钮、四条向下轻微收分的木腿和必要围板；抽屉仅保留运行时动作锚点，当前没有面向用户的开合交互。蓝灰织物桌垫使用连续低薄软垫表面、与侧缘重叠贴合的压缩包边和低对比内缩分段线迹，不再形成 bumper 包围内嵌工作场的托盘层级；外部贴纸交互范围与顶面高度保持稳定。背景、胡桃木承载面和蓝灰工作面支持现有墨绿色本子，使本子保持最深视觉焦点，同时避免已否决 V1 的粉米木桌与婴儿薄荷桌垫组合。3D 本子保持长边:短边 `5:3` 的竖向手帐比例，使用带四角对称斜切压线和细密可读织纹的墨绿色布面软壳；完全闭合及书脊贴桌立起时，前封面、连续圆背和后封面由同一个可形变壳体网格构成，不再渲染独立 D 型书脊或装饰性装订肩。闭合页芯从封面内缩，三侧以 12 层实例化暖纸边表现页口层次；封面中央放置一块可自定义的倒角黄铜铭牌和两颗圆顶铆钉，铭牌文字为单行、最多 12 个 Latin 字母/数字/基础标点的深色金属轻微凸起 Text3D；不支持字符显示校验错误，空值保持空铭牌，不再渲染书签。左右半册一开始摊开，闭合连续壳体就退出，由同材质的左右封面板接替；封面板从闭合位置随同一展开进度连续移动到各自的全开中线补偿，不在末端突变。左右半册以镜像、同速角位移落下；旧的 5 张实例页片与约 9 次快速翻页已删除。全开末段把左页堆降到与右页同高并精确转到 `π`；不再创建或显示额外的连续顶层纸面，左右页堆和各自页口层直接作为 3D 打开终态。封面布、纸面/纸口和黄铜使用相互独立的 PBR 响应；关闭沿同一时间轴逆向合拢为书口向上的直立姿态，再以贴桌书脊为轴落回桌面。3D 与 DOM 纸面均不绘制横线。
- `DD-20260813-004` 保存的 V1-V10 十个桌面配色候选已被用户全部否决，作为负向证据保留。无参数产品页与 production build 暂时继续使用 V2 作为运行回退值，但该状态不代表视觉验收通过。

- 首版不提供自由走动、房间扩建或复杂装修。

### 4.2 一本按日期组织的本子

- 打开本子时默认进入当天记录。
- 打开本子默认进入阅读模式；左页展示当前游标日期的贴纸并提供“前往贴纸工作台”入口，右页显示同一日期的正文。
- 今天与过去日期使用同一套“编辑 → 书写 → 收笔”入口保存短文本；“阅读 / 编辑”由一个按“阅 / 读 / 编 / 辑”竖排并上下滑动的切换按钮承担，“书写 / 收笔”以“图标 / 书 / 写”或“图标 / 收 / 笔”竖排在其下方；历史贴纸继续只读。
- 日期切换使用打开的双页本子与独立的上一页/下一页按钮触发受控仿真纸张翻页视觉；页面内容本身不再承担整页翻页命中。翻页动画层只表现纸张、正反面和光影，不渲染额外日期文字。仿真需要表达纸张绕书脊的方向、弯折感、正反面和光影，但不引入真实纸张动力学、布料/软体物理引擎或第二个 WebGL Canvas。
- 正在书写且内容发生变化时，翻页、切回阅读和关闭本子会被阻止并提示先收笔；首版不自动保存草稿。
- 编辑模式的右侧工具列在“书写 / 收笔”下方提供字体入口：点击后向本子方向展开“纸页宋体、玄冬楷书、随峰体”三项；开发环境额外提供仅供评估的“云峰晶晶体”。所选字体同时作用于 textarea 和保存后的正文，以当前浏览器 `localStorage` 保持；正文仍是纯文本。云峰晶晶体不进入生产构建，生产环境遇到该开发偏好时回退纸页宋体。随峰体来自 cjkFonts 官方 `The Peak Font Plus V1.002`，随项目离线分发并保留 SIL Open Font License 1.1 来源记录。
- 首版的“笔”是交互入口和视觉物件，不要求模拟真实笔迹或完整手写引擎。

### 4.3 一个贴纸制作器

- 贴纸工作台是与本子并列的独立入口，不读取日记正文草稿。
- 可以把短文本或本地图片交给固定版本的开源 `CatsJuice/sticker-forge` 制作成贴纸；不得以自研外观替代该制作核心。
- 文字可以选择内置颜色与材质；图片支持保留矩形、本地自动抠图和 Canvas 2D 手动修整。
- 图片只在当前浏览器处理，原始上传不持久化；确认后的 source PNG 与 Forge flat PNG 保存在 IndexedDB。
- 完成后可选择放到桌面或当前日期的日记；两个表面都支持放置、移动、`15°` 旋转、删除和重开恢复。
- 制作阶段可以体验 Sticker Forge 的材质与 peel；实例不持久化 peel 瞬时状态，也不运行独立 renderer。

### 4.4 一个旧痕迹入口

- 用户可以从抽屉或等价空间物件进入过去记录。
- 首版优先保存旧文字和贴纸引用。
- 首版不包含语音录制、播放或语音资源管理。

### 4.5 一盏状态明确的台灯

- 台灯提供可选的氛围状态，不是进入记录模式的强制入口。
- 灯光状态可以保存。
- 台灯不承担复杂主题商城或场景装修能力。

## 5. 首版核心验收场景

### 场景 A：留下当天记录

1. 用户打开工作台。
2. 用户打开本子，从阅读切到编辑并点击“书写”。
3. 用户输入一句话并点击“收笔”。
4. 用户重新打开页面后仍能看到当天内容。

### 场景 B：把文字或图片变成空间痕迹

1. 用户从桌面独立打开贴纸工作台，选择文字或图片。
2. 图片可保留矩形、自动抠图或手动修整。
3. 用户选择放到桌面或当前日期的日记，并在允许区域落位。
4. 贴纸可以移动、`15°` 旋转和删除；重新打开页面后仍保持表面、位置和方向。

### 场景 C：找回过去内容

1. 用户打开旧痕迹入口。
2. 用户按日期找到过去记录。
3. 用户可以看到该记录关联的贴纸或资源。

## 6. 建议数据概念

这些是首版产品概念。当前源码已实现 `DailyEntry`、图片 source asset、`StickerDefinition`、`StickerRenderAsset` 和双 surface `StickerInstance`；其余仍是预计概念：

| 概念 | 职责 |
| --- | --- |
| `DailyEntry` | 某一天的标题、文字记录与创建、更新时间；标题今天默认“今天”，历史页默认“日记” |
| `StickerSourceAsset` | 用户确认后的图片 source PNG；不保存原始上传，首版不包含音频 |
| `StickerDefinition` | 文字或图片贴纸的 source 引用与 Forge 视觉定义 |
| `StickerRenderAsset` | Sticker Forge 确认时生成的透明 PNG Blob 与固定来源版本 |
| `StickerInstance` | 某张贴纸在桌面或指定日期日记上的位置、旋转和关联定义 |
| `DeskState` | 灯光、当前打开物件和桌面级持久状态 |

持久化数据应独立于 Three.js 对象。Three.js 场景只负责把这些状态呈现为空间物件和交互结果。

首版使用 IndexedDB 在当前浏览器本地保存数据，不建立账号、服务端数据库或云同步。清除站点数据、切换浏览器或更换设备不会自动迁移内容。

## 7. 明确非目标

- 自由走动和完整房间。
- 角色、装扮和开放社交。
- 多人协作或双人空间。
- AI 自动生成内容。
- 贴纸交易市场和数字藏品。
- 桌面上的持续 peel 物理、剥离状态持久化、撕起声音和每张贴纸独立 WebGL renderer；制作阶段可使用 Sticker Forge 自带的材质与 peel 预览。
- 远端图片抠图、云端图片处理与保存原始上传。
- 已放置图片的无损重新抠图、复杂路径编辑和图层系统。
- 语音录制、播放和语音资源管理。
- 复杂真实手写、钢笔物理或墨水模拟。
- 完整主题商城和自由家具装修。
- 账号体系、跨设备同步和云端备份。

## 9. 已确认的范围决策

1. 贴纸完整 MVP 支持文字、矩形图片和本地透明轮廓抠图；`DD-20260808-002` 已批准并实现图片与双目标首切片。
2. 首版不包含语音。
3. 本子使用打开的双页模型与受控的仿真纸张翻页视觉；双页下方使用不显示日期的左右弯曲箭头按钮触发上一页/下一页。允许用 DOM/CSS 3D 透视、纸面明暗和投影表现纸张方向与弯折感，但不引入真实物理引擎或第二个 WebGL Canvas。该规则由 `DD-20260809-001` 取代原“只做轻量翻页”的限制。
4. 台灯是可选氛围状态，不是记录流程的强制入口。
5. 数据先使用 IndexedDB 本地持久化，不做账号和云同步。
6. 文字与图片贴纸制作必须真实使用固定版本的 `CatsJuice/sticker-forge`；Dear Desk 负责本地抠图、业务状态、桌面/日记放置与持久化，并保证任意时刻只有一个活跃 WebGL Canvas。
7. 贴纸工作台是独立入口；日记贴纸按日期独立于正文存在。
8. 日记左页固定留白，右页只显示当前游标日期；打开默认阅读，今天与历史正文共用“编辑 → 书写 → 收笔”流程，dirty 草稿阻止离开且不自动保存。该交互由 `DD-20260809-004` 批准并实现。
