## 1. 产品定位

Dear Desk 不是一个以 3D 画面为卖点的日记工具，而是一个会随着使用逐渐留下痕迹的私人工作台。

它的首版目标是验证用户是否愿意反复回到同一张桌子，并对自己积累的空间状态产生记忆和珍惜。Three.js 服务于空间记忆、物体手感和时间沉积，不单独作为展示效果存在。

## 2. 目标用户行为

用户可以在三分钟内完成一次轻量记录：

```text
坐下 -> 打开本子留下文字，或独立制作一张贴纸 -> 放在桌面或日记 -> 离开
```

用户不必每天写长文。一次有效记录可以只是一句话、一张照片或一个当天关键词。

## 3. 首版要验证的问题

1. 用户是否愿意连续七天回到工作台。
2. 用户是否开始记住某件内容被放在什么位置。
3. 用户是否因为已有痕迹而不愿意重置桌面。

第三个问题是首版最重要的产品信号。它代表桌面开始形成普通日记工具缺少的情感壁垒。

## 4. 建议首版范围

### 4.1 一张可持续保存的桌面

- 桌面具有稳定视角和有限的可放置区域。
- 当前桌面场景包含一个无陈设、非交互的程序化书房壳体作为视觉背景：室内尺寸为 `42 × 33 × 18`，地板顶面与桌子保持既有 `y=-5.025` 接地锚点，北墙包含位于桌后方中央的真实四格窗洞；桌面默认进入可同时看全桌面和窗户的正面固定机位，该壳体不提供自由走动或房间装修能力。
- 场景不使用深度雾；renderer 背景只是清屏色，不是实体。书房顶部隔离面负责避免背景从开顶视线切入房间模型，墙面不会因雾化或背景露出而与 V12 背景混色。
- V12 当前源码颜色以 `src/scene/models/material-library.ts` 为准：背景 `#8FA89E`、桌垫工作面 `#2F432D`、桌垫垫体与包边 `#283E29`；此前段落中的 V12 色值已由后续手动修订替代。
- 用户摆放的内容在重新打开页面后仍然存在。
- 当前默认视觉采用“明亮轻拟物 Animal Desk”材质版本 `V2.2`：场景使用冷灰背景，程序化中深胡桃木桌为暖纸工坊风格的三抽屉书写桌，包含一块厚圆角台面、窄—宽—窄抽屉带、三枚暗金黄铜旋钮、四条向下轻微收分的木腿和必要围板；三只抽屉均由底板、左右侧板、后板和独立前面板组成，顶部敞开，中央宽抽屉已经作为“旧痕迹”入口开放，支持简短滑出/收回和 DOM 等价按钮，左右窄抽屉仍不承担功能。概念图还原后的低明度橄榄苔绿织物桌垫使用连续低薄软垫表面、与侧缘重叠贴合的深色压缩包边和低对比内缩分段线迹，不再形成 bumper 包围内嵌工作场的托盘层级；V12 工作面基础色为 `#423F2C`，垫体与包边为 `#303021`。桌垫与本子封面直接共享确定性的 `cloth` 四通道纹理：3×3 低频起伏、17×15 纱线噪声和方向性经纬 ridge 共同生成中性 albedo、AO、height 与 roughness；两类材质仍以独立颜色、凹凸强度、粗糙度和 sheen 响应区分。用户改色时只更新主色便会保留同样的织物结构；外部贴纸交互范围与顶面高度保持稳定。冷灰背景、胡桃木承载面、偏橄榄的工作面与更冷更深的墨绿色本子通过色相和明度分层。3D 本子保持长边:短边 `5:3` 的竖向手帐比例，使用带四角对称斜切压线和细密可读织纹的墨绿色布面软壳；完全闭合及书脊贴桌立起时，前封面、连续圆背和后封面由同一个可形变壳体网格构成，不再渲染独立 D 型书脊或装饰性装订肩。闭合页芯从封面内缩，三侧以 12 层实例化暖纸边表现页口层次；封面中央放置一块可自定义的倒角黄铜铭牌和两颗圆顶铆钉，铭牌文字为单行、最多 12 个 Latin 字母/数字/基础标点的深色金属轻微凸起 Text3D；不支持字符显示校验错误，空值保持空铭牌，不再渲染书签。左右半册一开始摊开，闭合连续壳体就退出，由同材质的左右封面板接替；封面板从闭合位置随同一展开进度连续移动到各自的全开中线补偿，不在末端突变。左右半册以镜像、同速角位移落下；旧版复用 5 张实例页片制造约 9 次从第一页扫向中部的快速翻页已删除，`DD-20260824-005` 改为在摊开中后段让 5 张临时页片各自只翻动一次，从中央装订轴依次落向左侧，形成短促连续的页面扇动。临时页片共享一份几何和纸张材质，只在转场窗口可见，reduced-motion 下关闭；全开末段全部退出，再把左页堆降到与右页同高并精确转到 `π`。稳定终态不创建或显示额外连续纸面，左右页堆和各自页口层直接作为 3D 打开终态。封面布、纸面/纸口和黄铜使用相互独立的 PBR 响应；关闭沿同一时间轴逆向合拢为书口向上的直立姿态，再以贴桌书脊为轴落回桌面。3D 与 DOM 纸面均不绘制横线。
- `DD-20260813-004` 保存的 V1-V10 十个桌面配色候选已被用户全部否决，继续作为负向证据保留。`DD-20260825-002` 新增只改变桌垫角色色的 V11；`DD-20260830-001` 进一步确认 V11 单色不是概念桌垫的最终材质基准，新增 V12 和桌垫专属多尺度程序纹理，并将 V12 设为无参数产品页、production build、无效参数与重置的运行默认。V1-V11 历史值均未被改写。
- `DD-20260813-005` 已实现桌面空闲态的场景颜色编辑功能，可实时调整背景、桌面、桌框、桌腿、抽屉面、桌垫工作面、桌垫包边、本子外壳与本子书脊/接缝。场景当前不使用雾；颜色面板从右上调色板按钮左侧展开，桌面和窄屏都保留调色板、字体、自由视角与独立音频按钮，不再用面板替换或遮挡功能按钮；音频、颜色和字体三个向左面板全局互斥，打开任意一个都会关闭此前面板，任意时刻最多显示一个。`DD-20260825-003` 在面板中增加“颜色 / 预设”页签：当前九项颜色仍只存在页面状态并支持重置和复制 JSON；用户可把完整九色快照命名保存为自定义预设，每张紧凑图片卡片带保存当下纯 3D 场景与机位的新建 640 × 360 WebP/PNG Blob 和删除命令，点击后立即切换场景。预设列表一行显示两张卡片，不再展示图下九色色条，图片失败时使用中性占位；已有 320 × 180 Blob 保持兼容。列表首项仍读取不可删除的 V11 固定预览图，但点击、重置和刷新均应用当前 V12 九色；这是 `ego-browser` 不可用时保留的已知静态预览滞后，不作为 V12 材质证据。自定义记录和 Blob 保存到当前浏览器 IndexedDB v5，刷新后列表恢复但场景从 V12 启动，不自动应用上次预设。列表超出可用高度时只在面板内部滚动；当前不包含重命名、覆盖、排序、分享、云同步或预览更新。

- 首版不提供自由走动、房间扩建或复杂装修。

### 4.2 一本按日期组织的本子

- 打开本子时默认进入当天记录。
- 打开本子默认进入阅读模式；左页展示当前游标日期的贴纸并提供“前往贴纸工作台”入口，右页显示同一日期的正文。
- 今天与过去日期使用同一套“编辑 → 书写 → 收笔”入口保存短文本；“阅读 / 编辑”由一个按“阅 / 读 / 编 / 辑”竖排并上下滑动的切换按钮承担，“书写 / 收笔”以“图标 / 书 / 写”或“图标 / 收 / 笔”竖排在其下方；历史贴纸继续只读。
- 正文可以为空；用户仍可通过“收笔”结束书写并保存空正文，标题保持非空。
- 日期切换使用打开的双页本子与独立的上一页/下一页按钮触发受控仿真纸张翻页视觉；页面内容本身不再承担整页翻页命中。翻页动画层使用当前日期与目标日期的双页只读 DOM 快照，通过固定版本 `page-flip@2.0.7` 表达移动折线、弯曲页角、正反面和动态阴影；日期只作为原页面页眉的一部分出现，不叠加独立日期标签。它不接管真实正文表单、贴纸交互或业务状态，也不引入真实纸张动力学、布料/软体物理引擎或第二个 WebGL Canvas。
- 正在书写且内容发生变化时，翻页、切回阅读和关闭本子会被阻止并提示先收笔；首版不自动保存草稿。
- 首页右上角工具栈在调色板与自由视角之间提供全局内容字体入口，向左展开“纸页宋体、玄冬楷书、随峰体、志莽行书”四项。所选字体同时作用于日记日期、左页“贴纸”标题、阅读/书写态日记标题、textarea、保存后的正文和黄铜铭牌字形，并由翻页动画快照继承，以当前浏览器 `localStorage` 保持；日记正文、标题和铭牌文字仍分别使用既有纯文本/IndexedDB 结构，不保存字体副本。空贴纸页不再显示“尚未留下”，正文页不再显示“当前日期”或“旧日记录”；有贴纸时仍显示“n 张”，书写态继续显示“正在书写/正在收笔”。纸页宋体是 `Georgia -> Songti SC -> serif` 系统回退，不是项目随附字体；玄冬楷书、随峰体和志莽行书是当前生产本地字体，均按项目记录随资源保留 SIL Open Font License 1.1 来源/许可证文本。志莽行书来自 Google Fonts `Zhi Mang Xing` 上游 OFL 目录。云峰晶晶体已删除，不再作为开发或发布字体。按钮、菜单标签、HUD、翻页导航和纸页操作状态等通用 UI 继续使用 `animal-island-ui` 提供的 Nunito/Noto Sans SC，其整体许可证为 CC BY-NC-4.0，不受内容字体选择影响，也不纳入 OFL 内容字体清单。
- 首版的“笔”是交互入口和视觉物件，不要求模拟真实笔迹或完整手写引擎。

### 4.3 一个贴纸制作器

- 贴纸工作台是与本子并列的独立入口，不读取日记正文草稿。
- 可以把短文本或本地图片交给固定版本的开源 `CatsJuice/sticker-forge` 制作成贴纸；不得以自研外观替代该制作核心。
- 文字可以选择内置颜色与材质；图片支持保留矩形、本地自动抠图和 Canvas 2D 手动修整。
- 图片只在当前浏览器处理，原始上传不持久化；确认后的 source PNG 与 Forge flat PNG 保存在 IndexedDB。
- 完成后可选择放到桌面或当前日期的日记；两个表面都支持放置、移动、`15°` 旋转、删除和重开恢复。
- 制作阶段可以体验 Sticker Forge 的材质与 peel；实例不持久化 peel 瞬时状态，也不运行独立 renderer。

### 4.4 一个旧痕迹入口

- 用户可以从抽屉或等价空间物件进入过去记录。
- 首版优先保存旧文字和贴纸引用。
- 当前实现启用中央宽抽屉及 DOM 等价按钮；历史索引按月份汇总早于今天的正文与日记贴纸日期，选择日期后本子直接打开到该日。左右抽屉保持无功能，入口开合和上次阅读日期不持久化。
- 首版不包含语音录制、语音播放或语音资源管理；本子、纸页和抽屉的固定动作音效不属于语音能力。

### 4.5 一套可关闭的声音反馈

- 开本快速翻页、关本、日期翻页、中央抽屉打开和关闭使用本地动作音效；无效、被拦截或目标页读取失败的操作不播放。
- 右上角音频设置分别提供音乐与音效的快捷开关、音量滑杆和百分比。音乐默认关闭并保留 `30%`，音效默认开启并为 `60%`；两类偏好保存在当前浏览器 `localStorage`。
- 当前没有背景音乐资源；音乐设置先保存偏好，不请求不存在的文件或伪装为正在播放。后续接入音乐需验证首次用户手势、循环接缝与后台暂停。
- reduced-motion 继续播放动作音效；用户可以用音效开关独立关闭。音频加载或播放失败不得阻断本子、翻页或抽屉动作。
- 当前 4 条输入素材由用户授权纳入项目，但外部来源与公开再分发许可待补证；公开发布前必须补齐或替换。

### 4.6 一盏状态明确的台灯

- 台灯提供可选的氛围状态，不是进入记录模式的强制入口。
- 灯光状态可以保存。
- 台灯不承担复杂主题商城或场景装修能力。

## 5. 首版核心验收场景

### 场景 A：留下当天记录

1. 用户打开工作台。
2. 用户打开本子，从阅读切到编辑并点击“书写”。
3. 用户输入一句话并点击“收笔”。
4. 用户重新打开页面后仍能看到当天内容。

### 场景 B：把文字或图片变成空间痕迹

1. 用户从桌面独立打开贴纸工作台，选择文字或图片。
2. 图片可保留矩形、自动抠图或手动修整。
3. 用户选择放到桌面或当前日期的日记，并在允许区域落位。
4. 贴纸可以移动、`15°` 旋转和删除；重新打开页面后仍保持表面、位置和方向。

### 场景 C：找回过去内容

1. 用户打开旧痕迹入口。
2. 用户按日期找到过去记录。
3. 用户可以看到该记录关联的贴纸或资源。

### 场景 D：控制工作台声音

1. 用户从右上角打开音频设置。
2. 用户可以分别关闭音乐或音效，并独立调整两类音量。
3. 用户关闭音效后打开本子、翻页或操作抽屉，动作仍成功但不发声。
4. 用户刷新页面后，两个开关和音量恢复为上次选择。

| 概念 | 职责 |
| --- | --- |
| `DailyEntry` | 某一天的标题、文字记录与创建、更新时间；标题今天默认“今天”，历史页默认“日记” |
| `StickerSourceAsset` | 用户确认后的图片 source PNG；不保存原始上传，首版不包含音频 |
| `StickerDefinition` | 文字或图片贴纸的 source 引用与 Forge 视觉定义 |
| `StickerRenderAsset` | Sticker Forge 确认时生成的透明 PNG Blob 与固定来源版本 |
| `StickerInstance` | 某张贴纸在桌面或指定日期日记上的位置、旋转和关联定义 |
| `DeskState` | 灯光、当前打开物件和桌面级持久状态 |

持久化数据应独立于 Three.js 对象。Three.js 场景只负责把这些状态呈现为空间物件和交互结果。

首版使用 IndexedDB 在当前浏览器本地保存数据，不建立账号、服务端数据库或云同步。清除站点数据、切换浏览器或更换设备不会自动迁移内容。

## 9. 已确认的范围决策

1. 贴纸完整 MVP 支持文字、矩形图片和本地透明轮廓抠图；`DD-20260808-002` 已批准并实现图片与双目标首切片。

7. 贴纸工作台是独立入口；日记贴纸按日期独立于正文存在。
8. 日记左页固定留白，右页只显示当前游标日期；打开默认阅读，今天与历史正文共用“编辑 → 书写 → 收笔”流程，dirty 草稿阻止离开且不自动保存。该交互由 `DD-20260809-004` 批准并实现。
