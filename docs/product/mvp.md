## 1. 产品定位

Dear Desk 不是一个以 3D 画面为卖点的日记工具，而是一个会随着使用逐渐留下痕迹的私人工作台。

它的首版目标是验证用户是否愿意反复回到同一张桌子，并对自己积累的空间状态产生记忆和珍惜。Three.js 服务于空间记忆、物体手感和时间沉积，不单独作为展示效果存在。

## 2. 目标用户行为

用户可以在三分钟内完成一次轻量记录：

```text
坐下 -> 留下一点东西 -> 制作或选择一个贴纸 -> 放在桌上 -> 离开
```

用户不必每天写长文。一次有效记录可以只是一句话、一张照片或一个当天关键词。

## 3. 首版要验证的问题

1. 用户是否愿意连续七天回到工作台。
2. 用户是否开始记住某件内容被放在什么位置。
3. 用户是否因为已有痕迹而不愿意重置桌面。

第三个问题是首版最重要的产品信号。它代表桌面开始形成普通日记工具缺少的情感壁垒。

## 4. 建议首版范围

### 4.1 一张可持续保存的桌面

- 桌面具有稳定视角和有限的可放置区域。
- 用户摆放的内容在重新打开页面后仍然存在。
- 首版不提供自由走动、房间扩建或复杂装修。

### 4.2 一本按日期组织的本子

- 打开本子时默认进入当天记录。
- 用户可以输入并保存一段短文本。
- 可以查看过去日期的记录。
- 日期切换使用明确但轻量的翻页反馈，不模拟真实纸张物理。
- 首版的“笔”是交互入口和视觉物件，不要求模拟真实笔迹或完整手写引擎。

### 4.3 一个基础贴纸制作器

- 可以把短文本制作成贴纸。
- 支持用户图片制作基础矩形贴纸。
- 图片保持矩形边界；首版不提取透明轮廓，也不提供高级材质。
- 贴纸可以放置、移动、旋转和移除。
- 贴纸位置和朝向必须持久化。
- 首版不实现全息、闪粉、复杂反光、撕起声音或物理剥离。

### 4.4 一个旧痕迹入口

- 用户可以从抽屉或等价空间物件进入过去记录。
- 首版优先保存旧文字和贴纸引用。
- 首版不包含语音录制、播放或语音资源管理。

### 4.5 一盏状态明确的台灯

- 台灯提供可选的氛围状态，不是进入记录模式的强制入口。
- 灯光状态可以保存。
- 台灯不承担复杂主题商城或场景装修能力。

## 5. 首版核心验收场景

### 场景 A：留下当天记录

1. 用户打开工作台。
2. 用户打开本子并输入一句话。
3. 用户保存并离开。
4. 用户重新打开页面后仍能看到当天内容。

### 场景 B：把一句话变成空间痕迹

1. 用户选择一段短文本制作贴纸。
2. 用户把贴纸拖到桌面允许的位置。
3. 拖动贴纸时不会误操作相机。
4. 重新打开页面后贴纸仍保持原位置和方向。

### 场景 C：找回过去内容

1. 用户打开旧痕迹入口。
2. 用户按日期找到过去记录。
3. 用户可以看到该记录关联的贴纸或资源。

## 6. 建议数据概念

这些是预计概念，不是已实现的数据结构：

| 概念 | 职责 |
| --- | --- |
| `DailyEntry` | 某一天的文字记录与创建、更新时间 |
| `Asset` | 用户加入的图片资源；首版不包含音频 |
| `StickerDefinition` | 文字或基础矩形图片贴纸的内容与视觉定义 |
| `StickerInstance` | 某张贴纸在桌面上的位置、旋转、层级和关联来源 |
| `DeskState` | 灯光、当前打开物件和桌面级持久状态 |

持久化数据应独立于 Three.js 对象。Three.js 场景只负责把这些状态呈现为空间物件和交互结果。

首版使用 IndexedDB 在当前浏览器本地保存数据，不建立账号、服务端数据库或云同步。清除站点数据、切换浏览器或更换设备不会自动迁移内容。

## 7. 明确非目标

- 自由走动和完整房间。
- 角色、装扮和开放社交。
- 多人协作或双人空间。
- AI 自动生成内容。
- 贴纸交易市场和数字藏品。
- 全息、闪粉、物理剥离等高级 Sticker Forge 能力。
- 图片透明轮廓提取与高级材质。
- 语音录制、播放和语音资源管理。
- 复杂真实手写、钢笔物理或墨水模拟。
- 完整主题商城和自由家具装修。
- 账号体系、跨设备同步和云端备份。

## 8. 建议产品事件

| 事件 | 用途 |
| --- | --- |
| `desk_opened` | 观察回访频率 |
| `entry_saved` | 观察有效记录完成率 |
| `sticker_created` | 观察信息转为空间痕迹的比例 |
| `sticker_placed` | 观察核心循环完成率 |
| `past_entry_opened` | 观察用户是否回看沉积内容 |
| `desk_reset_requested` | 观察用户是否产生重置犹豫或实际重置 |

具体分析平台、隐私策略和事件字段不在本文范围内，需要在实现埋点前单独审批。

## 9. 已确认的范围决策

1. 贴纸支持文字和基础矩形图片，不做透明轮廓与高级材质。
2. 首版不包含语音。
3. 本子只做明确、轻量的翻页，不模拟真实纸张物理。
4. 台灯是可选氛围状态，不是记录流程的强制入口。
5. 数据先使用 IndexedDB 本地持久化，不做账号和云同步。
