## 1. 给阅读者的结论

上一轮实现让打开本子自动经过桌子正面再跟进近处。用户现在希望把镜头控制改成三个明确、可单独调整的固定位置，并用一个按钮循环切换。建议将桌面镜头整理为 `远处 / 正面 / 近处` 三个响应式预设，按钮每次只切到下一个位置，镜头在相邻或跨级预设之间平滑插值。

“切换视角”和“打开本子”保持两个不同意图：相机按钮只改变桌面观察位置，不自动开盖；点击本子或“打开本子”仍会进入日记。打开时临时聚焦到近处后开盖，关闭后返回用户打开前选中的桌面视角。三个预设的 `position / target / fov` 集中配置，后续可以直接调数值，不再把正面位置埋在一条自动路线的中间比例里。

## 4. 目标与非目标

### 4.1 目标

- 提供 `远处 / 正面 / 近处` 三个命名且集中可调的相机预设。
- 桌面端和移动端可分别调整每个预设的 `position / target / fov`。
- 使用一个相机按钮按固定顺序循环切换三个预设，并在按钮上显示当前视角名称。
- 每次点击只执行一次平滑的起终点插值，不再自动穿过全部三个位置。
- 切换期间防止重复触发造成并行动画；reduced-motion 快速落到目标预设。
- 打开本子时临时聚焦近处并开盖；关闭后恢复打开前选中的桌面视角。
- 保留单 Canvas、DOM 日记、贴纸流程和持久化边界。

### 4.2 非目标

- 不在用户界面增加 XYZ、target 或 FOV 数字输入框。
- 不增加三个独立按钮、分段控件、自由相机或 OrbitControls。
- 不修改本子模型、开盖角度、日记布局或贴纸行为。
- 不把镜头视角写入 IndexedDB；页面重开默认回到“远处”。
- 不修改 `DD-20260812-001` 所属材质、灯光、模型或视觉样式成果。

## 5. 方案说明

### 5.1 三个可调预设

将相机姿态明确命名为：

```text
far   = 远处：现有桌面斜视全景
front = 正面：桌子正面、距离较远
near  = 近处：靠近本子的聚焦取景
```

每个预设均包含 `position`、`target`、`fov`，并按桌面端 / 移动端集中声明。上一轮的 `desk / front / focus` 数值可作为初始值，但重命名为产品语义明确的 `far / front / near`，浏览器验收时只微调构图数值。

### 5.2 单按钮循环

桌面命令区增加一个 `Camera` 图标按钮，按钮可见文本显示当前预设：`远处`、`正面` 或 `近处`。点击顺序固定：

```text
远处 -> 正面 -> 近处 -> 远处
```

`aria-label` 和 tooltip 同时说明当前与下一视角，例如“当前远处，切换到正面”。切换动画期间按钮禁用，完成后才允许下一次点击；这仍是同一个按钮，而不是三个选项控件。

### 5.3 状态与本子关系

新增可序列化但不持久化的 `DeskCameraPreset = 'far' | 'front' | 'near'`，由现有 Zustand app store 拥有，默认 `far`。DOM 按钮与 R3F `CameraRig` 读取同一状态，避免通过事件或 ref 跨所有权同步。

镜头按钮只在 `notebookPhase === 'desk'` 时可见。本子打开时：

- 若当前已经是 `near`，相机无需长距离移动，直接进入现有开盖阶段。
- 若当前是 `far` 或 `front`，相机从当前位置直接插值到 `near`，到位后开盖；不再强制经过第三个预设。
- 用户选中的桌面预设保持不变；关闭本子合盖后，相机直接返回该预设。

这样“用户主动切视角”与“进入日记所需的临时聚焦”保持清晰分工。

### 6.1 核心数据结构变化

预计新增：

```ts
type DeskCameraPreset = 'far' | 'front' | 'near'

interface AppState {
  deskCameraPreset: DeskCameraPreset
  deskCameraTransitioning: boolean
  cycleDeskCameraPreset(): void
  settleDeskCameraPreset(): void
}
```

默认值为 `far`。状态只存在当前页面会话；不修改 Dexie schema、领域实体或 IndexedDB。具体动作命名可按现有 store 风格微调，但所有权和生命周期不变。

### 6.2 上下游与跨模块影响

- `App.tsx` 是镜头按钮的 DOM 消费者，`DeskScene.tsx` 是相机状态的 R3F 消费者，store 是唯一共享所有者。

- `NotebookObject` 无需理解 `DeskCameraPreset`。
- 页面隐藏时的 `settleNotebookTransition()` 仍可把本子阶段收敛；相机预设切换另有完成动作，避免按钮永久锁定。
- 贴纸制作、桌面贴纸选择和日记 dirty 保护继续优先控制桌面命令可见性。
