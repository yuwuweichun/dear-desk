## 1. 给阅读者的结论

当前样片像一张放在桌子后面的模糊墙纸：正面有窗和书架，但转动镜头很快会看见没有内容的侧面。本次把它升级为一个包住座位视野的柔和房间，增加左右墙、墙角、天花板边界和沿侧墙延伸的室内轮廓，并扩大可观察角度。

房间仍由项目代码生成，不依赖来源不明的网络扫描；加载失败时仍保留轻量房间壳，桌面、本子和贴纸继续可用。它解决的是固定座位附近的空间包围感，不实现自由走动或可近距离检查的真实扫描房间。

## 2. 用户需求

- 用户指出当前 Gaussian 样片只有一面墙，且摄像头旋转限制明显。
- 用户讨论过 Skybox 和程序化房间后，明确选择继续采用 Gaussian Splatting 并要求执行。
- Codex 将本次解释为：保留现有 Spark/SPZ 单 Canvas 管线，把项目自生成资产从单一后墙扩展为覆盖后方与两侧的房间，并相应放宽固定座位环绕；本次不引入许可不明的第三方扫描资源。

- `src/scene/MemoryRoomShell.tsx` 当前只有后墙与地面，没有左右侧墙和天花板，因此 Splat 加载前或失败时也会暴露单面结构。
- `src/scene/memory-room-profile.ts` 在实验开启时把每个相机预设的水平环绕限制为中心左右各约 `20°`；限制是为了隐藏单墙资产的盲区。
- `src/scene/MemoryRoomBackdrop.tsx` 允许最多 160,000 个 Gaussian，并已支持本地 SPZ 的异步载入、淡入、失败回退和清理，预计不需要更换 renderer 或增加第二个 Canvas。
- `docs/product/mvp.md` 把自由走动和完整房间列为非目标；扩大固定座位的受控观察范围不改变该产品边界。

合理推断：三面房间能显著减少“贴在后方的一面墙”观感，但项目代码生成的 Gaussian 仍不是摄影测量扫描，其真实感上限主要取决于空间层次、配色、遮挡和构图，而不是几何精度。

## 4. 目标与非目标

### 4.1 目标

- 让后墙、左右侧墙和墙角共同覆盖固定座位的主要视野。
- 把实验水平环绕从约 `±20°` 放宽到约 `±60°`，继续禁止平移和缩放。
- 让窗、书架、植物及侧墙陈设形成可辨识但低对比的空间层次。
- 保持资产可重复生成、来源明确、体积受控，并保留首屏与失败回退。
- 完成自动测试、构建、桌面与移动端视觉验收，并同步变更与架构文档。

### 4.2 非目标

- 不引入第三方真实房间扫描或处理新的素材授权。
- 不实现 360° 环绕、自由走动、平移、缩放或进入背景检查细节。
- 不让 Gaussian 背景响应实时重光照，也不加入全屏景深后处理。
- 不在本次直接启用 production 默认背景或新增用户可见设置。

## 5. 方案说明

1. 重构 SPZ 生成器，使平面 Gaussian 可沿 XY、YZ 和 XZ 三种方向分布；用同一固定 seed 生成后墙、左右侧墙和稀疏天花板边界。
2. 后墙继续保留窗、远处树影、书架和植物；侧墙增加延伸书架、窗帘、画框或柜体等大轮廓，避免三面墙只是同色平面。
3. 不重新加入 Gaussian 地板，避免透明椭球与清晰桌腿相交产生毛边；程序化 shell 继续拥有地板和实时接影。
4. `MemoryRoomShell` 同步增加左右墙和天花板承接面，使首帧与失败状态也完整包围主要视野；Splat ready 后 shell 降低不透明度，只作为深度与色调基底。
5. 将实验相机最大水平偏移改为 `Math.PI / 3`，即每个预设中心约 `±60°`；仍围绕桌面目标旋转，禁止平移与缩放。
6. 保持开发参数、动态 import、超时、淡入、单 Canvas 和资源释放链路不变；如 Gaussian 数量明显增加，则在现有 160,000 上限内控制密度并记录产物大小。

## 7. 风险、边界与回退

| 风险 | 发生条件 | 影响 | 缓解与回退 |
| --- | --- | --- | --- |
| 侧墙仍像平面贴图 | 只增加墙面而没有空间层次 | 包围感提升但真实感不足 | 增加墙角、纵深陈设和不同朝向的 Gaussian；保持低对比定位 |
| 更宽旋转暴露房间前方空缺 | 超过三面房间能覆盖的角度 | 看见空洞或墙背面 | 验收 `±60°` 极限；必要时只缩小到不低于 `±50°` 并记录偏差 |
| Gaussian 与桌腿相交 | 重新生成地面或近景点 | 前景出现毛边和漂浮 | Gaussian 不生成地板与桌面近景；shell 独占地面和接影 |
| 资产增大导致掉帧 | 侧墙密度过高 | 移动端排序和显存压力上升 | 控制在 160,000 个以内和 15 MB 以内；不达标则降低均匀墙面密度，优先保留轮廓 |
| 合成资产不够写实 | 用户期待真实扫描质感 | 视觉仍偏风格化 | 如实定位为自生成记忆房间；真实扫描资产另立任务并处理采集与授权 |
| 加载失败 | SPZ 404、解码或 WebGL2 问题 | Gaussian 不显示 | 保留完整三面 shell，核心操作继续可用 |
