## 1. 给阅读者的结论

当前字体设置只覆盖日记正文、输入正文和铭牌，没有完整覆盖纸页上的日期与标题；纸页右上角还重复显示“尚未留下”“旧日记录”“当前日期”等辅助状态。建议把日期、左页“贴纸”标题、右页日记标题及书写态标题输入纳入同一内容字体，同时从实时纸页和翻页快照中删除这三类辅助文字。

改动只调整日记 DOM 的展示范围，不改变已保存标题、正文、贴纸数量、日期游标、字体偏好或持久化结构。

## 2. 用户需求

- 用户原始要求：日期、“贴纸”、日记标题的字体也需要随着字体配置而变化。
- 用户原始要求：删去“尚未留下”“旧日记录”“当前日期”这些位置的文字。
- Codex 解释：上述字体范围同时覆盖正常阅读页、书写页和翻页动画生成的只读快照，避免翻页前后字形跳变。
- Codex 解释：“日记标题”既包含阅读态标题，也包含书写态标题输入；标题数据和默认值保持不变。
- Codex 解释：有贴纸时的“n 张”属于同一页眉状态位置。用户只明确要求删除“尚未留下”，因此本方案保留有贴纸时的数量；若用户希望该位置始终为空，需要在批准前补充确认。

## 4. 目标与非目标

### 4.1 目标

- 让实时日记页的日期、左页“贴纸”标题、阅读态日记标题和书写态标题输入跟随现有全局内容字体。
- 让翻页动画快照中的日期和左右页标题使用同一字体，保证动画前后视觉一致。
- 从实时页与翻页快照删除空贴纸页的“尚未留下”，以及右页的“当前日期”“旧日记录”。
- 保留有贴纸时的“n 张”数量、书写态“正在书写/正在收笔”、正文空态和贴纸空态引导。
- 增加针对性自动测试并同步文档事实。

### 4.2 非目标

- 不改变按钮、菜单、HUD、导航、状态消息或贴纸工作台等通用 UI 字体。
- 不改变日记标题默认值“今天”/“日记”、标题编辑规则或正文内容。
- 不改变字体选项、`localStorage` 键、IndexedDB schema、贴纸数据或翻页引擎。
- 不删除“这一页是空白的”“把今天的心情贴在这一页”等内容区空态。
- 不在本任务中处理未跟踪的 `DD-20260823-005` 任务。

## 5. 方案说明

继续使用现有 `.journal-panel[data-journal-font] -> --journal-writing-font` 单一字体映射，不新增字体状态。样式层把纸页日期、页标题和标题输入明确纳入该变量；翻页快照挂载在同一 `.journal-panel` 内，会继承完全相同的 CSS 自定义属性，不需要复制字体 ID 或引入内联样式。

页眉生成逻辑改为可选辅助状态：实时左页仅在贴纸数量大于零时显示“n 张”，空页不创建占位文字；实时右页不再创建状态节点。快照页采用同一规则，避免翻页中重新出现已删除文案。书写态的“正在书写/正在收笔”是当前操作反馈，不属于用户点名删除的日期类别状态，因此保留。
