## 2. 用户需求

用户原始要求：自由旋转视角按钮使用带旋转意图的图标，并增加 hover 动效；随后用户明确放弃该需求。

Codex 解释：图标需要同时传达“相机/观察”和“左右旋转/环视”两个语义；桌面端 hover 触发短促的立体左右翻转，键盘 focus-visible 同样可见，触摸设备不依赖 hover；按钮的启用/停用语义仍由现有 `aria-pressed` 和标签表达。

## 3. 当前源码事实

- `src/app/App.tsx` 的自由视角按钮为 `.free-camera-button`，使用 `aria-pressed={freeCameraEnabled}`，关闭态渲染 `CameraOff`，开启态渲染 `Camera`，点击调用现有 `toggleFreeCamera`。
- 当前自由视角实际使用 Three.js `OrbitControls`，按钮状态已经代表是否开启受限环绕视角；本任务不改变该行为。
- `src/styles.css` 已为 `.free-camera-button` 定义启用态高亮和 hover 高亮规则，但没有图标组合或旋转动画。
- 项目图标库是 `lucide-react`，底层图标集为 Lucide；已确认可搜索 `Camera`、`SwitchCamera`、`Rotate3d`、`RefreshCw`、`Repeat2`、`ArrowLeftRight` 等关键词，无需新增依赖。
- 项目已有 `@media (prefers-reduced-motion: reduce)` 约束入口；动效应遵循该无障碍约束。
- 当前工作树另有用户修改：`.codex/config.toml`、`package-lock.json`，以及上一项任务的 `src/styles.css` 和变更记录；本任务不得覆盖无关修改。

## 4. 目标与非目标

### 4.1 目标

- 让自由视角按钮图标同时表达摄像头与可环绕旋转。
- hover 和键盘 focus-visible 时提供一次短促、克制的旋转反馈。
- 保持现有点击逻辑、按钮尺寸、颜色状态、无障碍名称和 `aria-pressed`。
- reduced-motion 用户不播放旋转动画。

### 4.2 非目标

- 不改变 Three.js 相机控制、旋转范围、相机状态或业务状态。
- 不让图标持续旋转，不在按钮开启状态下自动循环播放。
- 不新增动画依赖、图标包、图片资源或第二个渲染层。
- 不改变房间背景、颜色、字体或其他右上角按钮。

## 5. 方案说明

### 5.1 图标选择

推荐优先在 Lucide 中搜索 `SwitchCamera`：它最接近“相机 + 两个方向箭头”的既有语义。如果其构图仍不符合视觉稿，再使用 `Camera` 与 `ArrowLeftRight` / `RefreshCw` 组合；其中双箭头图形负责静态语义，摄像头本体负责动态翻转。`Orbit` 不再作为候选图标。

### 5.2 动画行为

推荐对摄像头主体使用 `transform: perspective(40px) rotateY(...)` 的 CSS 动画，让镜头产生左右立体翻转；双箭头使用较小幅度的水平/旋转反馈。桌面鼠标 hover 或键盘 focus-visible 时播放一次，约 `560ms`，使用 `ease-in-out`。不使用持续循环，避免按钮成为持续闪动元素。

### 5.3 实现边界

在 `App.tsx` 增加一个仅负责装饰展示的图标 wrapper 和确认后的双箭头图标；在 `styles.css` 增加 3D 透视、Y 轴翻转、箭头定位与 keyframes，并在 reduced-motion 媒体查询中禁用动画。装饰 SVG 使用 `aria-hidden="true"`，按钮现有 label 继续承担可访问名称。

## 6. 预计改动与影响评估

- 修改 `src/app/App.tsx`：引入 `Orbit`，把自由视角按钮内容改为摄像头主体与轨道提示组合。
- 修改 `src/styles.css`：增加组合图标定位、hover/focus-visible 一次性旋转和 reduced-motion 覆盖。
- 修改 `src/app/App.test.tsx`：验证按钮仍有正确标签、`aria-pressed` 和组合图标节点；不对 CSS 动画实现细节做脆弱的像素断言。

### 6.1 核心数据结构变化

无。只增加装饰性 DOM 节点和 CSS 规则；自由视角状态、持久化和 Three.js 调用链不变。

### 6.2 上下游与跨模块影响

只影响右上角自由视角按钮的图标展示与 hover/focus-visible 反馈。不会影响相机控制、移动端点击、其他按钮或场景渲染。

## 7. 风险、边界与回退

| 风险 | 发生条件 | 影响 | 缓解与回退 |
| --- | --- | --- | --- |
| 小型轨道图标在窄屏过密 | 组合图标间距或尺寸过大 | 摄像头识别度下降 | 轨道层使用约 10–11px、绝对定位在右下角；必要时移除轨道层，仅保留主体 |
| 动画造成晕动不适 | 动画持续或忽略系统设置 | 无障碍体验下降 | 只播放一次，并覆盖 `prefers-reduced-motion: reduce` |
| hover 规则覆盖按钮状态 | CSS 选择器优先级不当 | active 样式或图标色异常 | 复用现有 `.free-camera-button` 状态规则，动画只作用于内部轨道层 |
