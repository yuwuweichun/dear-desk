## 1. 给阅读者的结论

当前动画不是单纯的镜头偏差：3D 本子以闭合书册中心为根位置，打开时固定后壳不动，只让前壳和左页绕左侧书脊翻到另一边，展开包围盒因此向左增长；近景相机仍看向固定桌面目标。这个单侧展开结构既会在早期暴露闭合页芯、壳体和临时翻页片的组合关系，也无法天然保证展开后的视觉中心稳定。

建议把开场重做为一个以本子中心锚点为基准的连续动作：整册先从桌面竖起，中央书脊保持在桌面中心线上，随后左右壳体与两侧页堆围绕书脊中线对称摊开；若保留纸页动作，只表现从中间跨页向两侧归位的少量翻页，不再从第 1 页连续快速扫到中部。最终打开跨页和动画起点共享同一中心锚点，再切换到 DOM 日记，从而避免横向漂移和交接跳位。

## 2. 用户需求

**用户原始要求：**

- 当前“打开书壳 → 从第 1 页快速翻页 → 弹出二维 UI”的策略会暴露错误或不适合展示的模型结构。
- 本子打开后没有居中。
- 新策略为“本子先竖起，然后从中间摊开”；允许保留翻页，但翻页应从中间开始。
- 动画前后书本都要保持在桌子的居中位置。

**Codex 解释：**

- “从中间摊开”按中央书脊作为稳定轴处理，左右封壳与左右页堆共同形成打开动作，而不是继续沿用单侧前壳翻到左边的展示逻辑。
- “从中间开始翻页”按打开时已处于书芯中段解释：可用少量中间纸页向左右分流来增强手感，但不再播放从第一页开始的约 9 次快速逐页动画。
- “动画前后居中”不仅约束两个端点，也约束竖起、半开、全开的中间关键帧；以本子的世界空间视觉中心为验收对象，不以模型根节点数值恰好为零代替视觉检查。
- 关闭默认采用对应的逆向空间动作：DOM 日记退出后，3D 打开跨页从中心合拢，整册落回桌面，再恢复用户原桌面机位。若实际实现发现逆向动作会与现有交接产生新的主要体验差异，需先回写并重新确认。

## 4. 目标与非目标

### 4.1 目标

- 将 3D 打开动作改为“居中竖起 -> 从中央书脊向左右摊开 -> 稳定打开跨页 -> DOM 日记接管”。
- 去掉从第 1 页开始的高速连续扫页观感；若保留纸页动作，改为中段起始、次数少、服务于两侧页堆归位。
- 让闭合、竖起、半开、全开四类关键姿态的世界空间视觉中心保持在同一桌面中心锚点，桌面端与移动端都不出现明显横向漂移。
- 动画中不暴露只为旧翻页策略服务的闭合页芯缩放、临时翻页池穿插或不合理壳体拼接。
- 保持 reduced-motion、页面失焦结算、关闭流程和 3D/DOM 单画布交接可用。

### 4.2 非目标

- 不修改 DOM 日记内部的上一页/下一页 CSS 翻页交互。
- 不修改正文、贴纸、日期游标、IndexedDB schema 或持久化行为。
- 不引入纸张物理、布料模拟、第二个 WebGL Canvas 或外部动画库。
- 不借本任务重做本子的材质、铭牌、织纹或桌子/桌垫模型；只有为新铰链和中间摊开所必需的节点组织与局部几何调整在范围内。
- 不改变用户打开本子和关闭本子的入口、dirty 草稿保护或阅读/编辑业务规则。

## 5. 方案说明

建议把一个 `opening` 总进度拆成可测试的视觉时间轴，但不增加持久化或业务 phase：

1. **聚焦：** `approaching` 继续负责相机进入近景；近景构图以本子中心锚点为目标。
2. **竖起：** opening 前段让整册围绕穿过本子中心的展示 pivot 从桌面平放姿态竖起。wrapper 同步做高度补偿，使书脊中心在屏幕中不横向漂移，也不穿过桌垫。
3. **中间摊开：** opening 中段以中央书脊为共同基准，把左右封壳和两侧页堆向左右对称展开。稳定打开态的左、右页宽和中缝围绕 X=0 对称布置。
4. **中段纸页：** opening 后段最多使用少量视觉页片，从书芯中部向两侧归位；动作可与摊开局部重叠，但不再先展示完整闭合页芯再连续扫 9 页。若少量页片仍暴露结构，允许直接省略翻页，只保留页堆弹性落定。
5. **交接：** 3D 全开端态与 DOM `.journal-book` 使用相同的屏幕中心和宽高比例；状态进入 `editing` 后按现有所有权隐藏 3D、挂载 DOM。
6. **关闭：** 以稳定全开 3D 跨页接回 DOM，左右半册向中线合拢，整册落回桌面；`retreating` 再把相机恢复到用户原机位。

实现上优先给模型发布一个单一的“展示进度”runtime API，由模型工厂内部计算竖起、摊开、纸页与中心补偿；`NotebookObject` 只管理计时和 wrapper 级桌面定位。这样关键几何关系仍由模型所有者负责，场景组件不需要了解每块封面或页堆的局部坐标。

### 11.4 页沟与纸张立体感修正

### 11.5 左右同速与连续跨页曲面修正

用户于 2026-08-17 18:08 CST 指出左半册打开速度慢于右半册，并进一步明确两页纸应以曲面连续连接，不应保留任何可见缝隙。源码原因已确认：公共书脊回落使用 `lowerProgress = smoothstep(spreadProgress, 0.08, 0.82)`，右半册在展开进度约 `82%` 时已经落平；左半册还要继续完成自身 `π` 旋转，因此最后一段只剩左侧运动。终态虽然把页缝缩窄到 `0.06`，但 `center-gutter-valley` 仍是独立网格与独立材质，结构上仍然是“三块纸面拼接”。

修正范围：让公共书脊回落严格使用 `1 - spreadProgress`，使右半册世界角度从 `π/2 -> 0`、左半册世界角度从 `π/2 -> π`，在任意展开进度下角位移绝对值一致；终态用一张横跨左右页堆的连续顶页网格接替左右独立顶页，中线由同一网格的连续顶点曲率形成凹谷，不再创建或显示独立页缝网格、独立纸根材质或颜色分界。中间动画仍可使用左右独立顶页随各自半册运动，接近全平时切换到几何位置一致的连续跨页曲面。

实际实现：`src/scene/notebook-transition.ts` 删除提前结束的 `lowerProgress`，直接把 `uprightProgress` 绑定为 `riseProgress * (1 - spreadProgress)`；`src/scene/models/geometry.ts` 新增单一索引几何 `createContinuousOpenSpreadGeometry()`，在同一顶点网格中生成左右纸面、纸根肩部、中央凹曲率和书头/书尾纸边；`src/scene/models/create-notebook-model.ts` 在全平末段显示 `continuous-open-page-spread` 并隐藏左右独立顶页，彻底删除 `center-gutter-valley`；`src/scene/models/material-library.ts` 同步删除临时 `paperGutter` 材质。新增测试逐点验证左右角位移镜像相等，并断言终态只有连续跨页节点、旧页缝节点不存在。

### 11.6 摊开过程闭合书脊结构退出修正

用户于 2026-08-17 18:36 CST 提供动画过程截图，指出中线书头和书尾会短暂冒出绿色书脊结构，随后在终态跳变消失。源码对应关系是：`book-joints` 虽在 `spreadProgress >= 0.08` 后隐藏，但摊开前段仍会显示装饰性装订肩；`continuous-case-shell` 则一直保留到 `spreadProgress >= 0.985` 才瞬间切换为左右平放封面板，所以闭合圆背端部会在几乎整个摊开过程中从纸面中线露出，并在末端发生可见切换。

修正范围：删除不承担旋转、碰撞或持久化职责的 `book-joints`；连续圆背壳体只服务完全闭合和书脊贴桌立起阶段，一旦左右半册开始分开便退出；左右独立封面板在同一阈值接替，并让中线补偿从闭合位置随 `spreadProgress` 连续插值到全开位置，避免封面板在切换帧横向跳动。真正的开合轴继续由 `tabletop-spine-hinge`、`coverPivot` 和 `pagePivot` 承担。

实际实现：`createBookJoints()`、`NotebookModelNodes.bookJoints`、`NOTEBOOK_MODEL_SPEC.joint` 及对应资源/测试契约全部删除。`setOpenProgress()` 以 `spreadProgress > 0.001` 作为闭合壳体与独立封面板的结构所有权边界，并每帧把前后封面板 X 补偿设置为 `±OPEN_COVER_CENTER_OFFSET × spreadProgress`；关闭沿相同公式逆向回到零。模型测试新增展开中段断言，确认连续壳体隐藏、两块封面板可见且补偿恰为终值的一半，同时确认场景中不存在 `book-joints`。
