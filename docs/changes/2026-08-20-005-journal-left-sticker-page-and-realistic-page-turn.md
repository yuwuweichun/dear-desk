## 1. 给阅读者的结论

当前双页日记把左页作为上一页的导航命中区，右页承载当前日期正文与贴纸。建议把双页语义调整为：右页继续显示当前日期正文，左页固定作为同一日期的贴纸展示区，并在左页提供进入现有独立贴纸工作台的入口；上一页和下一页改由一组清晰、可访问的显式按钮承担。

翻页仍沿用 DOM/CSS 方案和单活跃 WebGL Canvas 约束，但会补强纸张绕书脊的弯折、正反面内容、边缘高光、阴影和运动阶段，使方向和纸张厚度更可信。该方案不改变现有贴纸按日期持久化模型，也不引入真实纸张物理引擎。

- 原本由页面承担的翻页功能改为一组翻页按钮。
- 翻页动画希望更仿真。

- 翻页按钮改为只显示弯曲方向箭头的视觉控件：向左弯曲箭头表示上一页，向右弯曲箭头表示下一页；保留按钮的中文无障碍名称、提示和边界禁用语义。

- “前往贴纸工作台”调用现有 Sticker Forge 工作台入口；进入方式和返回路径仍需确认。

## 4. 目标与非目标

### 4.1 目标

- 左页明确成为当前日期的贴纸展示区，能展示该日期已保存的全部日记贴纸。
- 左页提供“前往贴纸工作台”入口，并沿现有 Sticker Forge 流程制作贴纸；完成后仍可选择放到日记或桌面。
- 上一页/下一页改为一组独立、可聚焦、可读屏的按钮，按钮负责边界禁用、未收笔拦截和翻页状态锁定。
- 翻页动画表达纸张从书脊掀起、弯折、翻转、落下的阶段，保留 `prefers-reduced-motion` 降级。
- 保持按日期的贴纸坐标、IndexedDB v3 数据和单 WebGL Canvas 约束不变。

### 4.2 非目标

- 不改变 Sticker Forge 固定 commit、图片处理、贴纸材质或持久化格式。
- 不把正文或贴纸渲染迁移到 Three.js，不新增第二个 WebGL Canvas。
- 不加入日历选择器、未来日期、搜索、批量整理或贴纸编辑器重做。
- 不引入真实纸张动力学、布料/软体物理引擎或逐顶点物理模拟。
- 不改变桌面贴纸的坐标、选择、旋转和删除行为。

## 5. 方案说明

### 5.1 页面与入口

推荐的阅读态布局是“左页贴纸、右页正文”。左页继续使用 `JournalStickerLayer`，但数据取当前右页日期而非上一条历史日期；没有贴纸时显示轻量空状态和进入工作台按钮。右页保留正文、标题、阅读/编辑模式和今天的书写能力。

翻页控制组放在双页本子下方或书脊附近的独立控制栏，只保留上一页和下一页两个弯曲箭头按钮，不再显示当前日期/页序文本。页面表面不再注册整页导航命中，避免贴纸拖动、正文阅读和翻页互相抢占事件。

### 5.2 工作台跳转

进入工作台必须先结束或暂停当前本子编辑上下文，再卸载日记 DOM，挂载现有 Sticker Forge；这样继续满足单活跃 WebGL Canvas。推荐默认行为是：若当前没有未保存草稿，关闭本子并进入工作台；若存在已修改未收笔内容，阻止跳转并提示先收笔。制作取消或完成放置后返回桌面，是否自动重新打开本子需用户确认。

### 5.3 仿真翻页

保留 `journalTurnPhase` 与 `journalPendingCursor` 状态机。扩展 `PageTurnSheet` 为带真实前后内容快照的翻页面，使用中缝 transform origin、分段 `rotateY` / `rotateX`、页面曲率伪影、边缘高光和方向性阴影；动画完成后才提交目标游标。按钮在 loading/turning/writing 状态下锁定，失败时回滚到原跨页。`prefers-reduced-motion` 使用短淡入或无旋转切换。

## 7. 风险、边界与回退

| 风险 | 发生条件 | 影响 | 缓解与回退 |
| --- | --- | --- | --- |
| 工作台跳转丢失未保存正文 | 编辑态直接离开本子 | 用户草稿丢失 | 未收笔时阻止跳转；保留当前草稿状态，不自动保存 |
| 左页贴纸与拖动事件冲突 | 左页仍保留整页导航命中 | 无法稳定选择/放置贴纸 | 删除页面命中层，只让贴纸对象和按钮接收 pointer |
| 翻页动画在移动端掉帧 | 过多阴影或 3D 层 | 阅读体验抖动 | 限制翻页层数量与阴影复杂度；移动端和 reduced-motion 降级 |
| 从本子进入工作台破坏单 Canvas | 两个 renderer 同时存在 | WebGL context 竞争 | 先结束日记/桌面场景，再挂载 Forge；沿用现有 destroy 生命周期 |
| 历史数据展示错位 | 使用错误日期读取贴纸 | 贴纸出现在错误页面 | 继续以 `rightDate` 作为当前日期事实，增加按日期测试 |

回退方案是恢复当前 `JournalPage` 的日期页序和透明导航按钮，保留数据与 repository 不变；不需要清库或迁移。

## 9. 待确认项与决策

1. **左页贴纸的日期语义（推荐 A）**
   - A：左页显示与右页同一日期的贴纸，右页显示正文。语义稳定，适合“贴纸区 + 正文区”并列。
   - B：左页显示上一条历史日期的贴纸，右页显示当前日期正文。保留更多历史信息，但左页仍承担跨日期语义，和“固定贴纸区”不完全一致。
2. **前往工作台后的返回行为（推荐 A）**
   - A：关闭本子后进入工作台；取消/完成后回到桌面。实现简单，符合单 Canvas 所有权。
   - B：保留本子上下文，制作结束后自动重新打开本子。体验连续，但需要额外的内存状态和恢复路径。
3. **翻页按钮位置（推荐 A）**
   - A：放在双页本子下方的独立控制栏，左/右箭头配合文字或 aria label。
   - B：放在本子左右外侧的浮动按钮，视觉更接近书签控件，但移动端布局更紧张。
4. **贴纸入口在左页的形态（推荐 A）**
   - A：左页空状态和贴纸区底部提供“前往贴纸工作台”按钮。
   - B：固定显示在左页工具栏，即使已有贴纸也可见。入口更易发现，但占用贴纸展示空间。
5. **翻页按钮视觉（本次补充修正，推荐 A）**
   - A：只显示左右弯曲箭头，使用 `aria-label` 和 hover/focus 提示补充“上一页/下一页”文字语义。
   - B：保留“上一页/下一页”文字矩形按钮。当前实现形态，信息明确但占用横向空间，与你的附图目标不一致。
