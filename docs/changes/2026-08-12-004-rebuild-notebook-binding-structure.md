## 1. 给阅读者的结论

当前模型别扭不是因为“书脊少了一点细节”，而是结构关系错误：封面、页芯和书脊分别像独立厚板，左侧书脊是一根额外放置的胶囊体，没有包住页芯根部，也没有形成封面铰链。继续改粗细或颜色只能掩盖问题。

建议把本子重建为一册可信的圆背软壳日记本：一个连续的封面系统包住一个完整页芯，页芯根部形成窄而连续的装订背；前后封面在装订背两侧通过柔性压槽转动。闭合时只看到一个完整书体和自然页口，打开时左右页从同一书根展开，不再出现“垫子叠垫子”或独立胶囊书脊。

## 2. 用户需求

**用户原始反馈：** “本子的书脊我觉得不对，就是这个本子很别扭啊，就是一本本子很难建模吗？”

**Codex 解释：** 用户否决的是当前本子的整体结构可信度，而不只是书脊材质或装饰。此次应重建本子的封面、装订背、页芯和铰链关系，目标是第一眼看起来就是一本正常的本子；不再以添加装饰掩盖结构问题。

## 3. 当前源码事实

- `src/scene/models/create-notebook-model.ts` 用 `createCover()` 分别创建前后封面；每个封面又由 bumper、cloth shell、board core/liner 三层圆角厚板叠成。
- `createSpine()` 单独创建 `planner-soft-spine`，它是缩放后的 `CapsuleGeometry`，位于 `X = -1.5`。它与封面、页芯没有共享几何边界，只在销毁分组中和中缝归为 `binding`。
- `front-cover-pivot` 位于 `[-1.5, 0.3, 0]`，前封面和左页芯挂在该 pivot 下；右页芯、后封面和胶囊书脊留在根组。打开时只旋转 pivot，并分别抬高左右页芯和中缝。
- 左右页芯分别由厚圆角 page stack、inset band、弯曲顶页、实例化页缘和页线组成。闭合时两个页芯以不同 `X/Y` 位置叠放，打开时没有共同的可见书根截面。

- `NotebookObject` 只依赖 `createNotebookModel()`、`setOpenProgress()`、透明命中盒和稳定节点 `coverPivot`；正文与贴纸不进入 Three.js。

## 4. 目标与非目标

### 4.1 目标

- 让闭合本子呈现一个连续、比例合理的书体，而不是三层圆角垫叠放。
- 让书脊成为页芯根部与封面之间的装订结构，不再使用独立胶囊体模拟。
- 建立后封面、装订背、前封面之间的连续关系，并在书脊两侧形成细窄压槽/柔性铰链。
- 让页芯从同一个书根展开，页口在三条非装订边自然内缩并显示有限分层。
- 保留现有居中、正向、放平、hover、点击命中、相机路线和开合状态机。
- 保持无书签、无封面角标、无装饰圆钉、无粉色书脊装饰。

### 4.2 非目标

- 不模拟逐张纸张、缝线物理、布料或软体动力学。
- 不把正文、textarea 或日记贴纸移入 WebGL，不增加第二个 Canvas。
- 不修改日期、翻页、保存、贴纸持久化或 Zustand 状态协议。
- 不重做桌子、桌垫、灯光和已确认的近处相机构图。
- 不增加封面文字、logo、书签、扣带、铆钉或其他装饰来补偿结构。

## 5. 方案说明

采用“圆背软壳日记本”的程序化结构，而不是继续维护独立胶囊书脊：

1. **完整页芯**：闭合时视为一块连续 text block，厚度明显小于封面总厚度；三条页口边相对封面内缩，装订边收束成较窄的 page spine。
2. **装订背**：使用沿本子长边延伸的半圆/圆弧截面几何，与页芯根部贴合。它表达纸张签帖或胶装根部，不表达一根外加软管。
3. **连续封面系统**：后封面、窄 spine cover 和前封面共用一致的厚度与表面材质。spine cover 包住 page spine 外侧，两侧各留一条浅压槽，压槽同时定义真实的开合轴。
4. **开合层级**：后封面与右页芯保持在基准侧；前封面与左侧可见页面围绕压槽轴展开。中缝跟随开合抬起，但始终连接同一 page spine，不单独漂浮。
5. **克制的纸张表达**：保留顶页轻微拱度和有限页缘层；删除让页芯像另一层软垫的 oversized inset band 观感。书本识别依靠封面包边、页口 inset、装订根和铰链阴影，而不是粉色附件。

计划先在现有 `createNotebookModel()` 工厂内完成，不引入外部模型文件。圆背截面使用程序化 `BufferGeometry` 或低段数圆柱/挤出几何，继续受现有 draw call、三角形和纹理预算约束。

### 9.1 用户否决后的新决策

用户提供的近景截图证明第二版仍然是错误结构：上下封面像两块厚软垫，白色页芯只是一条悬空夹层，左侧圆背仍像附着在封面外的软管，圆背端部还有外翻截面。此前“结构可信”的验收判断无效，不能继续以调半径、厚度或颜色修补。

新方案改为**硬壳平背日记本**，并彻底删除当前本子工厂内部装配：

1. 闭合书体只有一个完整 `textBlock`，它同时形成前口、天头和地脚三条真实纸口；不再用左右两块 page stack 在闭合时重叠。
2. 上下封面是两片薄硬壳板，厚度显著小于页芯；封面只比页芯四周多出窄包边，不使用软垫式大圆角和多层 shell/core/liner 叠板。
3. 左侧使用窄直 `spineCase`，截面为薄矩形壳，不用半圆柱、胶囊、圆管或外露端帽。spineCase 与上下封面之间各有一条内凹 book joint，视觉上明确封面从哪里翻开。
4. 所有闭合部件共享同一基准：页芯夹在上下封面之间，纸口沿 Y 方向具有真实厚度；书脊壳只覆盖页芯装订边，不伸到封面上方或下方形成外翻片。
5. 打开动画不复用闭合 `textBlock` 伪装两页。进入 opening 时，由同一规格派生的 front cover、left leaf、right leaf 和 gutter 围绕 book joint 展开；3D 只负责短暂开合，完成后仍由 DOM 双页接管。
6. 颜色继续使用当前青绿封面与暖白纸，但造型识别完全依靠真实比例和截面，不添加书签、徽章、铆钉、环带或彩色书脊附件。
