### 3.1 参考图观察事实

- 对象分类：单体家具中的复合硬表面物件，`primaryDomain = object`；适合作为风格化实时道具，复杂度预计为 `complex`。
- 整体轮廓：长方形厚桌板，四角为较大的平面圆角，边缘有连续倒角；四腿形成开放桌下负空间，整体近似左右对称。
- 宏观分件：桌板、前框/抽屉带、四条桌腿。
- 中观分件：左窄抽屉、中央宽抽屉、右窄抽屉，三只抽屉各有圆形旋钮；侧围板与后部支撑只部分可见。
- 微观特征：沿桌板长轴的木纹、抽屉面独立圆角与细缝、旋钮的底座/冠部层次、桌腿向下轻微收分、木材边缘的低粗糙度高光。
- 材质观察：木材是中深暖棕色、非金属、缎面至半哑光响应，并有低幅木纹和粗糙度变化；旋钮是暗金黄铜样金属，边缘高光比木材集中。
- 单图限制：背侧桌腿部分遮挡，后围板、桌板底面、抽屉箱体深度与内部均不可见；这些区域只能沿家具结构连续性做低到中置信度推断。

## 4. 目标与非目标

- 为所有可见分件提供稳定名称，并让抽屉、旋钮、腿和框架在 `sculptRuntime` 中可点击、可爆炸拆分；抽屉保留线性滑动 action/sockets。
- 保持当前材质库生命周期、资源预算、相机、桌垫命中面、本子位置和桌面贴纸坐标兼容。
- 按 `img2threejs` 完成参考准入、复杂度/质量契约、细节清单、严格规格验证、分阶段构建、确定性门槛、多角度截图、比较图和有界修正循环。

### 4.2 非目标

- 不改变桌垫、本子、贴纸、日记、相机状态机或 IndexedDB 数据结构。

## 5. 方案说明

实施时先为本任务初始化 `.img2threejs/state.json` 的 `generic` 流程，并在每个阶段与修正循环前运行 `forge/next.py`。同一参考图的旧 assessment/spec/render 作为历史证据，但新的本地状态、入图准入、质量契约、细节覆盖和阶段审阅必须归档到 `docs/assets/model-reviews/dd-20260816-002/`，避免把 2026-08-10 的通过结论直接当成新实现的证据。

模型继续由 `createDeskModel(materials, options)` 返回一个 plain Three.js `Group`。几何策略如下：桌板使用现有平面独立圆角挤出；围板和抽屉面使用圆角板几何；四腿使用连续收分的圆角方柱几何；旋钮使用底座圆柱与压扁球冠组成的实例化系统。抽屉各自挂在 slide socket 下，旋钮通过 knob socket 与抽屉保持附件关系。桌板、框架、腿、抽屉面和黄铜分别使用现有共享材质角色，必要时只对桌子专属材质参数做有证据的调整。

第一优先级是相机与轮廓，第二优先级是三抽屉/四腿的结构比例和连接，第三优先级是木纹方向、材质响应与旋钮层次。每次修正只处理一个根因组，明确记录改动数值、原因和仍未匹配之处。
