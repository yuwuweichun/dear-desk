## 4. 目标与非目标

### 4.1 目标

## 5. 方案说明

在 `AGENTS.md` 做以下最小改写：

1. HTML 文档规范来源：删除对 `/Users/song/Desktop/docs-html/AGENTS.md` 的依赖，改为创建或实质修改 HTML 文档时必须使用 `$bun-html-docs`；技能不可用或无法读取 `SKILL.md` 时暂停并提示修复，不得静默改用其他生成方式。
2. HTML 文档浏览器操作与视觉验证：本地可用时统一使用 `ego-browser`；不可用时跳过视觉验证，并在任务记录和交付说明中写明原因及需要用户手动验收的内容。
3. 前端视觉与交互：本地可用时使用 `ego-browser` 覆盖桌面端和移动端；不可用时跳过这一步，记录未覆盖风险，并明确告知用户手动验收桌面端与移动端。

`$bun-html-docs` 和 `ego-browser` 的降级策略有意不同：HTML 生成技能承载必须遵守的内容与实现规范，因此缺失时暂停；`ego-browser` 受平台和本地安装条件限制，因此缺失时保留人工验收路径。“可用”指当前执行环境已经具备可正常运行的 `ego-browser` 能力。本任务不要求为了通过门槛临时安装工具，也不把 Windows 上不可用的 `ego-lite` 视为必需替代品。
