## 1. 给阅读者的结论

当前翻页动画会在书页翻转层的正反两面渲染起止日期，因此日期只在动画进行时短暂出现在页面底部。建议保留纸张、光影和 3D 翻转效果，但删除翻页层中的日期内容，让翻页期间和翻页结束后的视觉语义一致。

修复后，翻页过程中不会在本子下方或翻页面片上出现额外日期文字；翻页按钮、右页正常日期标题和现有动画行为不变。

## 2. 用户需求

### 用户原始要求

- 翻页时底下会出现日期文字，翻页结束后消失。
- 这是 bug；该位置不需要显示日期。

### Codex 解释

- 附图仅说明翻页动画期间出现了不应存在的日期视觉，不新增其他布局或交互要求。
- 删除 `PageTurnSheet` 正反面的日期文本，保留翻页纸张本体、动画、按钮和正常页面日期。

## 3. 当前源码事实

- `src/features/journal/JournalPanel.tsx` 在 `journalTurnPhase === 'turning'` 且存在 `journalTurnDirection`、`pendingDate` 时挂载 `PageTurnSheet`。
- `src/features/journal/PageTurnSheet.tsx` 引入 `formatLocalDate`，并在 `.page-turn-front` 与 `.page-turn-back` 中分别渲染 `fromDate`、`toDate`。
- `src/styles.css` 的 `.page-turn-face` 将内容贴近页面底部对齐，因此日期会在约 720ms 的翻页动画期间出现在截图所示位置。
- 翻页完成后 `PageTurnSheet` 卸载，日期文字随之消失；右页自身的 `.journal-date` 属于正常页面标题，不是本次 bug 的目标。
- 现有 `src/features/journal/JournalPanel.test.tsx` 覆盖翻页层出现和游标结算，但没有断言翻页层不含日期文字。

## 4. 目标与非目标

### 4.1 目标

- 翻页动画期间不再渲染起止日期文字。
- 保持页面翻转、纸张纹理、阴影、边缘高光、动画时序和 reduced-motion 行为不变。
- 增加回归测试，确保翻页层没有日期文本且正常页面日期仍可用。

### 4.2 非目标

- 不改变右页正文的日期标题。
- 不调整翻页按钮位置、图标、禁用逻辑或日期导航状态机。
- 不修改日记、贴纸或 IndexedDB 数据结构。
- 不改变翻页动画的时长、方向或视觉参数。

## 5. 方案说明

在 `PageTurnSheet` 中移除日期格式化依赖和正反面 `<span>`，保留两个空的页面面作为纸张动画与光影承载层。由于日期只由该组件额外注入，删除内容不会影响 `journalCursor`、`journalPendingCursor` 或翻页完成回调；`fromDate`、`toDate` 也可从组件接口和调用处移除，避免保留无效数据路径。

选择组件层删除而非 CSS 隐藏，是因为日期不属于翻页动画的产品语义；这样 DOM、无障碍树和截图中都不会存在隐藏/短暂显示的日期节点，风险面最小。

## 6. 预计改动与影响评估

- `src/features/journal/PageTurnSheet.tsx`：移除 `formatLocalDate`、`fromDate`、`toDate` 和正反页面日期节点。
- `src/features/journal/JournalPanel.tsx`：调用 `PageTurnSheet` 时不再传入 `fromDate`、`toDate`。
- `src/features/journal/JournalPanel.test.tsx`：在翻页动画层出现时断言其不包含日期文本，同时保留翻页结算断言。
- `docs/product/mvp.md`：若当前产品事实仍提及翻页层日期，补充“不显示动画期间日期”。
- 本次不预计修改状态层、样式动画参数、持久化或公共 API。

### 6.1 核心数据结构变化

不修改任何持久化模型、状态字段或事件协议。仅收窄 `PageTurnSheetProps`，把不再用于视觉渲染的 `fromDate` 和 `toDate` 从组件参数中删除；翻页游标仍由 `journalPendingCursor` 在动画完成后提交。

### 6.2 上下游与跨模块影响

影响范围限于日记翻页组件、其唯一调用方和对应测试。`formatLocalDate` 仍由正常日记页面使用；贴纸、工作台、状态存储、Canvas 生命周期和其他页面不受影响。
