## 1. 给阅读者的结论

当前打开动画并不是单纯把旋转方向写错了。沿书脊长边旋转所需的轴向确实是本子局部 `Z` 轴，但源码把前封面和整块左页片同时挂在一个 `coverPivot` 下，以同一角度刚性旋转；这个 pivot 又同时承担封面压槽和纸页页根两种不同的结构职责。因此动画看起来像一整块厚板绕偏内的轴翻过去，而不是封面从装订压槽抬起、纸页从书脊页根稍后跟随。

建议把结构拆成封面轴和页根轴，二者沿同一书脊方向但使用各自真实的局部原点，并用一条连续进度驱动有先后关系的封面、页片和闭合页芯过渡。这样不改变打开入口、状态机和 DOM 日记，只修正 3D 本子离桌到 DOM 接管前的机械关系和动画细节。

## 3. 当前源码事实

- `src/scene/NotebookObject.tsx` 在 `notebookPhase === 'opening' | 'closing'` 时，从 `coverPivot.rotation.z / openAngle` 取得起点，以一条 `easeInOutCubic` 曲线将单一进度传入模型的 `setOpenProgress()`。
- `src/scene/models/create-notebook-model.ts` 只有一个 `front-cover-pivot`。前封面和 `left.pages` 都是它的直接子节点，因此二者始终共享完全相同的旋转角、角速度和旋转原点。
- 当前 pivot 位于 `NOTEBOOK_MODEL_SPEC.coverHinge = [-1.38, 0.2925, 0]`，轴向元数据为 `[0, 0, 1]`。本子封面位于局部 `X-Z` 平面，书脊沿 `Z` 延伸，所以绕 `Z` 转是正确的轴向；问题在于同一个原点被同时用于封面压槽和纸页页根。
- 前封面中心通过 `frontCover.position.x = 1.38` 从 pivot 还原到根组 `X = 0`。以封面宽 `3.2` 计算，pivot 距封面左外缘约 `0.22`，表达的是封面压槽位置，不是纸页真正的装订根。
- 左页片通过 `left.pages.position.x = 1.38` 挂在同一 pivot 下；其宽度 `2.92`，变换后的左缘约为根组 `X = -0.08`，没有以自身左缘落在页根轴上。这说明当前“左页”实际上以封面中心关系定位，而不是以页根关系定位。
- `setOpenProgress()` 在进度大于 `0.01` 时立即隐藏完整闭合页芯、书脊壳与书槽，并立即显示左右薄页片。该拓扑切换发生在动画刚开始时，缺少可见连续性。
- 右页片只做 `Y` 向线性下移；左页片与前封面无相对滞后、弯曲或落页阶段。现有 `createCurvedPageGeometry()` 只提供静态曲面，不随翻动进度改变。
- `src/scene/models/model-factories.test.ts` 只断言单 pivot 的位置和角度、左右页片净空以及可见性，没有断言封面轴与页根轴分离、阶段节奏或中间帧连续性。
- `docs/product/mvp.md` 规定打开后由 DOM 双页日记接管正文；本修复无需改变 DOM 日记、IndexedDB 或贴纸所有权。
- 当前工作区已有本子比例、材质、结构和相机适配的未提交改动。本任务必须在这些真实改动上增量实施，不得恢复旧模型。

## 4. 目标与非目标

### 4.1 目标

- 为前封面和左侧翻动页片建立职责分离的旋转节点，轴都沿书脊长边，但原点分别落在封面压槽与纸页装订根。
- 让打开过程呈现“封面先起、页片稍后跟随、接近摊平时柔和落下”的连续节奏；关闭过程按相反顺序稳定复位。
- 消除动画开始 1% 时完整页芯与薄页片的明显跳变，保证关键中间帧没有悬空、穿模或厚度突变。
- 保持既有 `NotebookPhase` 状态机、相机路线、打开总时长、响应式入口与 DOM 日记接管边界不变。

### 4.2 非目标

- 不修改 DOM 日记中的前一天/后一天翻页动画、排版、编辑或保存行为。
- 不重做封面比例、墨绿色牛皮纸材质、桌垫、桌子、灯光或机位。
- 不引入骨骼动画、物理引擎、外部模型资产、第二个 WebGL Canvas 或新依赖。
- 不新增可逐张翻动的 3D 正文页，也不改变持久化数据。

## 5. 方案说明

保留模型根坐标和书脊方向，新增两个明确节点：`coverPivot` 继续位于前封面的压槽铰链中心，只拥有前封面；新增 `pagePivot` 位于纸页靠书脊的装订根，只拥有左侧翻动页片。页片几何以页根为局部零点重新定位，不再借用封面中心的偏移。

`setOpenProgress()` 仍接收 `0..1`，但在模型内部派生多个连续通道：封面使用完整进度；页片在封面已经抬起后开始追随，并在后半段逐渐赶上摊平角；右页片高度与可见性使用平滑阈值；静态曲面页的拱起量随中段增加、在落页时减弱。关闭时使用同一确定性映射反向播放，避免另建一套可能漂移的动画状态。

闭合页芯不会再在 `0.01` 处硬切。实现时优先用短暂交叉过渡和几何位置连续性表达厚页芯向左右页面的展开；若透明交叉导致深度排序伪影，则改为在封面遮挡区内切换，并用自动中间帧断言及浏览器画面确认切换不可见。
