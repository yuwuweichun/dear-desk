## 1. 给阅读者的结论

当前 Three 场景延续“深色暖木纸本工坊”的拟真方向，而刚完成的 DOM UI 已转向 `animal-island-ui` 的明亮、圆润、青绿与珊瑚点缀风格，两者并置时存在明显的视觉断层。本次建议保留桌面空间与纸本的触感，但把表现方式从深色拟真收敛为更明亮、低噪声、轮廓清楚的玩具感工作台。

用户将看到重新设计的桌子、桌垫、闭合/开合本子与内页：桌子成为浅暖色的稳定舞台，桌垫承担青绿主色，本子用暖白、青绿和珊瑚建立层级，纸页与现有日记控件共享色彩和阴影语言。现有打开本子、翻页、书写、贴纸放置和持久化行为不改变。

## 2. 用户需求

**用户原始要求：** UI 重构已结束；再次重构 Three 视觉空间，覆盖桌子、桌垫、本子和本子内页；重构视觉效果需要配合正在使用的 `animal-ui` 样式。

**Codex 解释：** “配合”不仅是替换颜色，还包括统一形状圆润度、明暗层级、材质噪声、接触阴影、交互反馈和桌面/日记视图的视觉连续性。为控制范围，本任务不改变日记业务流程，也不新增空间物件或持久化字段。

## 4. 目标与非目标

### 4.1 目标

- 统一桌面 Three 场景与当前 `animal-island-ui` 的色彩、圆润轮廓、层级和反馈语言。
- 重构桌子的比例、边角、表面分层与阴影，使其成为明亮、清楚且不抢 UI 的空间底座。
- 重构桌垫为青绿主视觉面，保留可识别边界与贴纸交互区域。
- 重构闭合与打开状态的本子，包括封面、书脊、页芯、装饰细节、书签及开合层次。
- 同步重构 Three 纸页与 DOM 日记内页，使聚焦前后保持同一纸张、线条、阴影与强调色逻辑。
- 保留现有单 Canvas、相机过渡、点击命中、贴纸放置、翻页、书写和持久化行为。

### 4.2 非目标

- 不改变日记数据模型、IndexedDB、状态机或日期规则。
- 不改变阅读/编辑/书写/收笔的主要交互，也不重做刚完成的通用 UI 控件。
- 不新增家具、自由相机、房间、复杂装修、真实纸张/布料物理或第二个 WebGL Canvas。
- 不引入新的外部 3D 模型、纹理下载或运行时网络依赖。
- 不在本任务内重构贴纸制作器或贴纸领域模型。

## 5. 方案说明

建议采用“Animal Desk”轻拟物方向：保留可触摸的桌、布垫和纸本，但用简洁色块、圆润轮廓、有限材质细节和稳定的短投影替代旧版深色、纹理密集的拟真表达。

1. **空间与光照：** 将深绿黑背景提升为浅薄荷或柔和中性背景，使用暖白环境光和柔和主光；保留遮挡和接触阴影以维持空间关系，但限制高反差暗部。
2. **桌子：** 使用一块厚圆角暖木台面、左右板式支撑和中央横梁建立稳定岛台轮廓；不包含柜体、抽屉、拉手或下层托板。
3. **桌垫：** 以 `animal-island-ui` 主青绿为来源建立低饱和主体，使用更浅内场、深一阶滚边和规则缝线；其交互 surface 尺寸与坐标契约保持不变。
4. **本子：** 封面采用青绿主体和暖白页芯，珊瑚用于书签/标识等小面积强调；减少金属和旧布质感，增强封面、页芯和书脊之间的圆润层叠。透明点击体与开合 pivot 契约保持不变。
5. **本子内页：** Three 页芯与 DOM 双页共享暖白纸、浅棕文字、柔和分隔线、青绿焦点与珊瑚日期点缀。DOM 页仍承担可读写内容，Three 页只负责聚焦和开合过程中的实体连续性。
6. **交互反馈：** 本子 hover 继续轻微抬起，但改为与 UI 按压阴影相呼应的短距离位移/亮度反馈；遵守 reduced-motion，避免新增持续漂浮动画。

视觉 token 将集中定义并由 Three 材质与页面 CSS 对齐，避免在多个模型工厂里散落互相偏离的近似颜色。不会直接把 CSS 变量传入 WebGL；Three 使用类型化场景 palette，CSS 使用对应 token，并由测试验证关键值和材质职责。

## 7. 风险、边界与回退

| 风险 | 发生条件 | 影响 | 缓解与回退 |
| --- | --- | --- | --- |
| 视觉统一变成单纯换色 | 保留旧版复杂写实几何与强纹理 | Three 与 DOM 仍有质感断层 | 同时评审轮廓、层级、材质、阴影和反馈；按对象逐项截图比较 |
| 明亮场景丢失空间层次 | 环境光过强或阴影过浅 | 桌垫、本子与桌面边界不清 | 保留柔和接触阴影和至少三级明度，桌面/桌垫/纸页使用不同粗糙度 |
| 外形调整破坏贴纸放置 | 修改桌垫交互 surface 或坐标契约 | 已有桌面贴纸位置错位 | 固定 interaction surface 与测试断言；仅重做可见网格 |
| 本子开合出现穿插 | 封面厚度、pivot 或页芯尺寸不协调 | 动画中模型穿模 | 保留 runtime API，测试闭合/半开/全开状态并做浏览器逐帧观察 |
| DOM 内页与 Three 本子不连续 | 两处颜色和比例独立调整 | 聚焦切换时出现跳变 | 使用同一视觉 token 映射，分别验证桌面态、过渡态和编辑态 |
| 移动端裁切或控件遮挡 | 桌子/本子比例和相机构图只按桌面调优 | 移动端主体不可用 | 桌面与移动端分别验收完整视图和日记视图；必要时仅调整现有响应式 camera pose |
| 性能回退 | 增加网格、纹理或阴影成本 | 低端设备掉帧 | 保持固定预算并运行模型预算测试；不新增后处理或第二画布 |

回退方式：本任务不迁移数据；可按文件恢复旧 palette、材质参数、模型工厂几何与页面样式。因公共模型 ID、交互坐标和持久化结构不变，回退无需转换用户数据。

### 11.4 最终结构重建实现

- `src/scene/models/create-desk-model.ts` 已整体替换：删除旧四条收窄桌腿、传统围板和内嵌矩形抽屉造型；新增双层悬浮台面、左右宽板式支撑、支撑内嵌面、中央下横梁、前部胶囊 rail、三个凸起胶囊抽屉和珊瑚胶囊拉手。旧 runtime 字段仅作为兼容别名映射到新结构节点。
