## 1. 给阅读者的结论

当前“背景音乐”被独立放在音乐音量控件和下一条分隔线之间，造成标题悬空、线条切断同一组音乐设置的问题。建议把曲目选择视觉上并入“音乐”分组，移除音乐音量与曲目选择之间的分隔线，让“背景音乐”成为紧凑的辅助标签并与分段按钮保持一致间距。

## 2. 用户需求

### 2.1 用户原始要求

- “背景音乐四个字，和上面的线也不好看，优化”。

### 2.2 Codex 对需求的解释

- 截图仅作为视觉证据，不包含新的文字或功能指令。
- 保留“背景音乐”四字，但弱化其独立标题感，调整为音乐设置组内的辅助标签。
- 上方分隔线不再切断音乐设置组；音效组与音乐组之间保留清晰边界。

## 3. 当前源码事实

- `src/features/settings/AudioSettingsControl.tsx` 当前依次渲染音乐音量控件、背景音乐 `SegmentedControl`、音效控件；音乐音量控件自身带底部边框。
- `src/styles.css` 的 `.audio-channel-control` 默认带 `border-bottom` 和 `padding: 14px`；`.audio-track-picker` 当前使用负上边距来贴近上方控件。

## 4. 目标与非目标

### 4.1 目标

- 消除“背景音乐”与上方分隔线之间的割裂感。
- 保留文字和当前分段选择交互。
- 让音乐标题、曲目按钮和音效分组形成清晰但不过度的层级。

### 4.2 非目标

- 不修改“宁静 / 愉悦”文案、音频逻辑、偏好结构或 animal-island 组件。
- 不重做整个音频设置面板，不新增依赖。

## 5. 方案说明

为音乐控件和背景音乐选择增加一个轻量包裹层，取消音乐控件自身在两者之间的底部边框，并将背景音乐标签改为紧凑的组内辅助文字。音乐组完成后再显示一条边界，分隔音效组；仅调整 CSS 间距、边框归属和标签颜色，不引入新的组件。
