## 1. 给阅读者的结论

日记标题输入框已显式关闭浏览器的自动补全、自动首字母大写、自动纠错和拼写检查；铭牌输入框此前缺少这些属性。修复后铭牌输入框会遵循相同的受控输入语义，浏览器不会用历史表单内容或语言辅助功能改写用户正在编辑的铭牌文字。

## 2. 用户需求

- 铭牌输入框的行为与日记标题输入框一致。
- 禁用浏览器自动补全及相关自动输入辅助，不改变用户输入的原始字符。

## 3. 当前源码事实

- `src/features/journal/JournalPanel.tsx` 的 `#journal-entry-title` 设置了 `autoCapitalize="none"`、`autoComplete="off"`、`autoCorrect="off"`、`name="journal-title"` 和 `spellCheck={false}`。
- `src/app/App.tsx` 的 `#notebook-nameplate-input` 当前只有 `autoFocus`、`maxLength`、受控 `value` 和 `onChange`，没有上述浏览器辅助属性。
- 铭牌输入仍由 `nameplateDraft` 控制，保存链路不需要改变；本次只补充 DOM 属性。

## 4. 目标与非目标

### 4.1 目标

- 为铭牌输入框补齐与日记标题相同的浏览器辅助输入属性。
- 增加属性回归测试，确保后续样式或表单重构不会删除这些约束。

### 4.2 非目标

- 不修改铭牌大小写修复、校验规则、保存值、IndexedDB schema 或 3D 渲染。
- 不禁用用户操作系统级输入法，也不改变日记正文 textarea 的行为。

## 5. 方案说明

直接在铭牌 `<input>` 上复用日记标题的五项属性：关闭自动首字母大写、自动补全、自动纠错和拼写检查，同时设置独立 `name`。React 状态和保存调用链保持不变，避免引入额外状态转换。
