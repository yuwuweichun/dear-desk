## 1. 给阅读者的结论

建议把 Dear Desk 的默认空间统一为 **“暖木纸本工坊”**：一张有温度但不过度写实的胡桃木书桌，搭配深苔绿书写垫、象牙纸、酒红小面积强调和旧黄铜细节；几何采用圆角、低多边形和轻微手作不规整，避免 Minecraft 的方块复刻，也避免写实资产拼盘。

这套方向直接服务产品的“私人工作台”和“使用后留下痕迹”：桌面是安静的空间容器，本子是主角，日记页像真实但清爽的活页纸，贴纸工作台像在同一张桌上展开的裁切垫与纸质工具抽屉。3D 场景和 DOM 不强行模拟同一种媒介，而是共享颜色、材质、边角、阴影、排版和物件语义，从而形成一个完整产品而不是三套界面。

本任务建议先完成视觉基线与最小纵向改造，不新增主题选择器、装修系统或日记功能。视觉方案批准后，Codex 再按桌面场景 → 本子与日记页 → 贴纸工作台 → 响应式与回归验证的顺序实施。

## 3. 当前源码事实

### 3D 桌面

- `src/scene/DeskScene.tsx` 的 `DeskContents` 是固定场景组合入口，拥有背景、雾、环境光、两盏方向光、桌体、桌垫、左侧纸张、本子、铅笔、杯子和桌面贴纸。
- 场景背景与雾均为 `#17201d`；桌体是尺寸 `[12, 0.8, 8]` 的棕色 `BoxGeometry`，桌垫是尺寸 `[8.7, 0.12, 6.25]` 的深绿色 `BoxGeometry`。两者使用纯色 `MeshStandardMaterial`，当前没有桌面纹理。
- 固定陈列只有左后侧纸张、中央偏左本子、右侧铅笔和右后方杯子。当前没有可见台灯、植物、收纳盘或其他空间层次物件。
- `Pencil` 使用低段数圆柱与圆锥，`Mug` 使用 28 段圆柱和 torus；它们与盒体本子、纸堆之间只有颜色上的弱关联，没有统一的造型规则。
- 桌垫顶面同时承担贴纸放置点击；视觉改造不能破坏 `placingDesk` 分支、世界坐标、贴纸选择或桌面 raycast。
- `CameraRig` 对桌面与本子聚焦分别维护桌面/移动端相机姿态。新增陈列必须同时避开默认镜头、本子聚焦镜头和封面打开路径。

### 本子与日记页

- `src/scene/NotebookObject.tsx` 使用盒体构成酒红封面、米色纸芯、深色书脊、金色装饰线与封面名牌；点击命中、悬停抬起、封面 pivot、打开/关闭动画均由该组件拥有。
- 本子世界位置、命中盒、封面 pivot 和开合阶段是 `CameraRig`、`JournalPanel` 与状态机的交互契约。视觉可以重做可见子网格，但不能用不带锚点的静态模型直接替换。
- `src/features/journal/JournalPanel.tsx` 以 DOM dialog 承载日期、标题、正文、贴纸层、字数、保存状态和操作。该边界符合 `DD-ADR-20260806-002` 的“普通表单使用 DOM，Three.js 是持久化状态的视觉投影”。
- `src/styles.css` 中的日记页使用半透明米白背景、Georgia/宋体、酒红保存按钮和极轻边框，已有纸本基础；但 `.journal-panel` 是完整矩形浮层，和下方 3D 书页之间缺少明确的内边距、装订、页眉和纸张纹理呼应。
- `src/sticker-workbench.css` 在 `.journal-paper` 上叠加 `JournalStickerLayer`。视觉改造必须保留归一化贴纸位置、拖动/选择层级和正文可读性。

### 贴纸工作台与全局 UI

- `src/features/stickers/StickerStudio.tsx` 的结构是左侧 Forge 预览区、右侧控制栏；文字/图片来源、抠图、材质和桌面/日记目标均属于已实现工作流。
- `src/styles.css` 的贴纸工作台使用灰米色舞台 `#cbc6bc`、浅纸色侧栏 `#f2ede3`、深绿选中态与酒红主操作。色彩与日记大体相邻，但舞台和控件呈通用工具软件语义，未表现为桌面上的裁切/装帧工具。
- `src/app/App.tsx` 在桌面稳定态显示“打开本子”和“贴纸工作台”两个 DOM 入口；`src/sticker-workbench.css` 让它们共用深色半透明按钮。全局顶栏、日期、反馈条和工作台控件需要纳入视觉 token，而不是只改 3D 模型。

### 产品、架构与工作区边界

- `docs/product/mvp.md` 明确 Dear Desk 不是以 3D 画面为卖点，而是让用户对逐渐积累的空间状态形成记忆和珍惜；主题商城、自由装修和完整房间系统属于非目标。
- `DD-ADR-20260806-002` 要求数据模型与 Three.js 对象分离；`DD-ADR-20260807-001` 要求桌面 R3F 与 Sticker Forge Canvas 不同时活跃；`DD-ADR-20260808-001` 要求日记贴纸继续由 DOM 层承载。
- `DD-20260806-006` 当前仍为 `待确认`，内容明确建议把整个场景改成 Minecraft 像素/体素风，尚未实施。用户在本任务中明确弃用该方向。
- 当前 Git 工作区存在产品、决策、场景、日记、贴纸、状态、持久化及依赖等多处其他未提交改动。本任务实施必须基于届时真实差异做局部编辑，不覆盖或回退用户现有修改。

### 合理推断

- 当前颜色已经隐约形成“深绿 + 米白 + 酒红 + 木色”，问题主要不是完全缺少审美方向，而是没有把它提升为跨 3D、纸页和工具界面的系统规则。
- 用户强调“整体视觉一体”意味着场景改造不能只替换桌面颜色；需要同时处理固定陈列、材质、DOM surface、排版和交互状态。
- 在未运行浏览器观察前，无法断言现有实际画面中的遮挡、比例和对齐质量；这些属于批准后实施阶段的桌面/移动端视觉验收内容。

## 4. 目标与非目标

### 4.1 目标

- 将 006 的 Minecraft 视觉方案明确标记为已弃用且未实施，保留历史设计与弃用原因。
- 为桌面、本子、日记页、贴纸工作台和全局操作入口建立一套可执行的统一视觉语言。
- 让默认空间第一眼呈现“暖木纸本工坊”：安静、温暖、风格化、清楚，具有生活痕迹但不杂乱。
- 以本子作为桌面视觉主角，贴纸和日记内容作为逐渐积累的个性痕迹，固定陈列只负责构图、光源和使用感。
- 保留现有本子开合、镜头、DOM 编辑、贴纸制作、桌面/日记放置、持久化和响应式行为。
- 建立可复用的视觉 token 和少量渲染配置，避免颜色散落在多个 CSS/JSX 文件中继续漂移。
- 为用户可见改动补充适当自动测试、构建检查和桌面/移动端浏览器验收。

### 4.2 非目标

- 不实现多主题切换、主题商城、自由摆放家具、完整房间、天气或昼夜系统。
- 不复用 Minecraft、Mojang 或其他品牌的原始模型、纹理和视觉标识。
- 不改变日记正文、贴纸来源、贴纸 placement、IndexedDB schema 或 Zustand 业务状态。
- 不把日记输入、贴纸工具表单或无障碍控件移入 WebGL。
- 不新增第二个 WebGL Canvas，不改变 Sticker Forge 固定集成边界。
- 不为装饰物新增交互、收藏、拖拽、购买或持久化状态。
- 不在本任务同时实施编号 001 的双页日记与仿真翻页；新视觉需为该任务预留空间，但不能把未批准的功能写成现状。
- 不为了追求“手作感”降低正文、表单标签、按钮状态和错误信息的清晰度。

## 5. 方案说明

### 5.1 视觉母题：暖木纸本工坊

核心不是复刻某个现成 IP，而是把 Dear Desk 想象成一间安静装帧师的私人桌面：物件使用了很久但维护良好，纸张、木头、布面、陶器和黄铜各有触感；整体经过轻度造型化，边角柔和、比例略夸张、细节克制。空间承载记忆，界面承载清楚的任务。

造型规则：

- 3D 固定物件采用软圆角盒体、低段数曲面和略厚的纸张层次，不使用体素方块，也不追求照片级写实。
- 材质以高粗糙度为主，允许轻微木纹、布纹、纸纤维和陶器颗粒；金属只用于极少量黄铜细节。
- 每个物件只保留一到两个辨识特征，控制小模型数量和材质数量，优先程序化几何与小型本地纹理。
- DOM surface 使用同一材质语义的二维表达：纸张靠暖白、细线和纤维噪点；布面靠深苔绿与柔和阴影；黄铜靠暖金色细边或图标强调，不使用伪 3D 重阴影。

### 5.2 调色板与视觉 token

建议以以下角色色作为第一版基线，实施时根据真实 WebGL 色彩管理和对比度微调，不把十六进制值视为未经测试的最终常量：

| 角色 | 建议色 | 用途 |
| --- | --- | --- |
| 深胡桃木 | `#6B4934` | 桌体主体、深色木边 |
| 蜂蜜木高光 | `#A7744F` | 桌沿、木纹明部、悬停暖光 |
| 深苔绿 | `#314B43` | 书写垫、本子布面、选中态 |
| 象牙纸 | `#F3E9D5` | 书页、日记页、控制栏 surface |
| 纸张阴影 | `#D8C8AD` | 分隔线、页边、禁用态 |
| 酒红印章 | `#A4484F` | 保存、危险/关键动作、日期章 |
| 旧黄铜 | `#C49A5A` | 名牌、书角、焦点环和少量强调 |
| 炭墨 | `#2D2923` | 纸面正文和深色图标 |
| 夜色墨绿 | `#17211E` | 场景背景、顶栏和深色浮层 |

CSS 预计整理为语义 token；Three.js 预计使用同一角色命名的只读场景 palette。两者共享设计角色但不强行共享运行对象。

### 5.3 桌子、构图与陈列

桌体改为暖胡桃木，顶面保留完整可贴放区域；当前大块绿色桌垫调整为深苔绿布面/皮面书写垫，弱化饱和度并增加细薄黄铜或皮革压线边缘。桌垫仍保持现有几何、点击和平面坐标契约。

固定陈列采用“主角 + 三角平衡”，避免铺满桌面：

1. **中央偏左：主本子。** 深苔绿布面硬壳、象牙纸芯、酒红书签、旧黄铜小名牌；保持当前交互位置和开合骨架。
2. **右侧：书写工具。** 一支酒红或蜂蜜木色六角笔，放在窄皮革笔托上；保留现有铅笔位置附近但建立清楚的静物组合。
3. **右后方：陶杯。** 暖灰白手作陶杯，深茶液面；降低圆滑工业感，使用较低段数与轻微不对称比例。
4. **左后方：纸张与票据托。** 当前纸块改为两三张错开的便签/旧票据和一个浅木或黄铜夹，作为使用痕迹而不是第二入口。
5. **后侧安全区：小型黄铜蘑菇灯。** 只作为可见光源与构图锚点，使用暖色局部光；位置需避开本子打开、贴纸放置和移动端裁切。若实测空间不足，可在首版删除灯而不是挤压主流程。

不建议首版加入植物、相框、书堆、时钟和大量收藏品。它们会让空间更像室内装饰模拟器，削弱本子和用户贴纸作为“痕迹”的主角地位。

### 5.4 本子样式

关闭状态强调“值得长期保存的私人本子”：深苔绿布纹封面、略厚圆角、象牙纸芯、酒红书签、旧黄铜名牌。名牌只使用项目现有名称/日期语义，不增加品牌装饰。书脊可以更厚，并用两条低调压线形成手工装帧感。

打开状态继续保留现有封面 pivot 和纸页锚点。可见页面使用分层纸芯和轻微页缘颜色差，不模拟昂贵的真实纸张物理。所有视觉子网格仍由 `NotebookObject` 管理；若采用圆角几何，应控制段数和阴影成本。

### 5.5 日记页样式

日记 DOM 应看起来是“落在打开本子里的可编辑纸页”，而不是盖住本子的通用弹窗：

- 象牙纸底，极轻纸纤维噪点或 CSS 生成纹理；不使用重度仿旧、污渍、撕边。
- 页顶保留日期与“今天”，但改为小号酒红日期章 + 清楚的衬线标题；正文继续使用高可读衬线字体栈。
- 正文区使用非常浅的横线或点线节奏，并确保文字行高与背景节奏对齐；贴纸层位于同一纸页坐标中。
- 使用酒红书签/页码作为方向提示，旧黄铜只用于焦点或极细分隔，不让金色成为大面积按钮色。
- 保存按钮、字数和错误信息保留明确状态。纸面主要动作使用酒红，次要动作使用透明/纸边样式。
- 桌面与移动端都保留足够可编辑高度；响应式时优先内容与触控尺寸，不强求展示完整书脊装饰。

### 5.6 贴纸工作台样式

贴纸工作台被解释为同一张桌上展开的“裁切与装帧台”：

- 左侧 Forge 预览区从普通灰底改为低饱和深苔绿裁切垫，可使用非常淡的网格/刻度，只作为方向感，不影响贴纸轮廓判断。
- 右侧控制栏使用象牙纸/浅亚麻 surface，分组像装帧工具抽屉上的纸签；控件继续保持标准 DOM 语义和足够触控尺寸。
- 来源切换、抠图工具和材质选择统一圆角、边框、悬停、选中、禁用和错误 token。深苔绿表示当前选择，酒红表示确认/关键动作，旧黄铜用于焦点和小标签。
- “放到桌面”和“放到日记”维持两个明确目标；不为统一风格改变工作流或文案层级。
- Manual Cutout 与主工作台共享同一 surface 和工具按钮规则，避免再次形成第四套界面。

### 5.7 全局界面与动效

- 顶栏继续使用夜色墨绿半透明层，但降低边框噪音；品牌字标、日期块、桌面两个入口和贴纸控制条统一 token。
- 图标继续使用当前 Lucide 线性图标，统一 stroke width；不引入另一套拟物图标。
- 动效保持短、稳、可关闭：本子悬停轻抬、按钮颜色/阴影过渡、纸页淡入。视觉改造不新增持续漂浮、粒子或环境动画。
- `prefers-reduced-motion` 继续生效，所有装饰动效不参与业务状态推进。

### 5.8 设计一致性判断标准

每个新增或修改元素都应回答四个问题：它属于木、纸、布、陶或黄铜中的哪种材质；它使用哪个角色色；它是否服务本子/贴纸/光源/操作之一；移除它是否会让界面更清楚。如果没有稳定答案，则不加入首版。
