## 1. 给阅读者的结论

截图中的左右页不是两种业务颜色。两侧顶页共用 `materials.paper`，其基色为暖白纸 `#f6efdc`，但左页在开合动画中经过 `pagePivot.rotation.z = Math.PI` 并对几何做过一次 Y 轴翻转与法线重算；右页直接朝向主暖色方向光。因此两面接收到的漫反射与半球光比例不同，右页被推向更深、更黄的视觉结果，左页更接近原始浅纸色。

这主要是光照入射角/法线方向问题，材质暖底色和纸张边缘层会放大差异，不是左右使用了不同的顶页材质。若目标是完全铺开后统一成左侧颜色，优先应让两侧顶页采用一致的朝向或一致的光照补偿；不建议先把纸材质整体改成更白，因为那会同时改变页口、边缘和闭合页芯的层次。

## 2. 用户需求

**用户原始要求：** 分析本子内页的材质、颜色与光照的关系，判断左右颜色差异是否是光照问题；完全铺开后的颜色希望接近截图左侧。

**Codex 解释：** 本次先定位原因和修复优先级，不直接实施视觉参数调整；“左侧颜色”理解为较浅、低黄度的暖白纸面观感，而不是把纸材质改成纯白。

## 3. 当前源码事实

- `src/scene/models/material-library.ts` 中 `paperMaterial` 是 `THREE.MeshStandardMaterial`，共用 `paper.albedo`、`paper.height`、`paper.roughness`，基色 `#f6efdc`、`roughness = 0.98`、`bumpScale = 0.0018`；`paperEdge` 使用 `#d8ccb0`，`paperBlock` 使用更深的 `#b9aa8b`。
- `src/scene/models/create-notebook-model.ts` 的 `createOpeningLeaf()` 为左右两侧创建相同的 `paperEdge` 页堆、相同的 `paper` 顶页和相同的实例化页口层。没有按 side 选择不同颜色的代码。
- 左页顶页几何先执行 `topGeometry.scale(1, -1, 1)` 并重算顶点法线，再挂到 `pagePivot`；开到完全铺开时 `pagePivot.rotation.z` 为 `Math.PI`。右页不执行该几何翻转，直接放在 `OPEN_PAGE_Y`。
- `src/scene/DeskScene.tsx` 使用暖色主方向光 `color="#fff4d6"`、`intensity={1.68}`、位置 `[-5.5, 10.5, 7]`，另有冷色方向补光 `intensity={0.28}`、半球光强度 `0.86` 与 `SceneEnvironment intensity={0.28}`。renderer 使用 ACES Filmic tone mapping，曝光 `0.98`。
- 主光从相机前侧/正 Z 方向照来。完全铺开后，左右页的几何朝向和法线变换不同，导致同一暖白 albedo 的漫反射明暗与黄度不同；高粗糙度只能抑制清晰镜面高光，不能消除漫反射色偏。
- 截图右页的大面积暖褐色更接近“受暖光照亮的浅色纸”，左页更接近材质基色；中线和前缘的更深色细带来自 `paperEdge`/页口层，不代表顶页颜色分支。
- 既有 `docs/changes/2026-08-17-006-diagnose-notebook-edge-glare.md` 记录过另一类边缘高光问题；当前本子布面 `bumpScale` 已为 `0.008`，本次截图的左右大面积色差不应优先归因于布面 bump。

## 5. 方案说明

建议后续若获批修复，按以下顺序做可回退实验：先在完全铺开状态临时统一左右顶页法线/朝向，确认色差是否消失；再单独降低暖主光或增加中性前侧补光，确认是否需要保留场景氛围；最后才考虑把 `paperMaterial.color` 从暖白轻微移向中性白。这样能区分几何法线问题、局部光照问题和材质底色问题。
