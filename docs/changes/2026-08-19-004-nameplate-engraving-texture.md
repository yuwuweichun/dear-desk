## 1. 给阅读者的结论

第一轮虽然消除了点阵字体和明显悬浮，结果仍是“画在透明平面上的金属色文字”。第二轮现已把固定方向彩色阴影替换为动态凹凸与粗糙度响应；仅更换暗酒红、黑色或铜色不再作为解决方案。

当前实现保留圆角黄铜牌体，并使用一层与牌体共享金属参数、紧贴顶面的动态铭刻表面。同一份当前字体 Canvas 字形生成色调、凹凸和粗糙度三张贴图：笔画中心略微凹入，边缘形成窄小斜面，槽底更粗糙并带极轻氧化暗化。识别线索来自随视角和灯光变化的明暗，而不是固定字体颜色。

## 2. 用户需求

- 文字必须看起来是刻在铭牌上，而不是贴在上面或悬浮。
- 消除像素字体观感。
- 采用已确认的稳定视觉方案；字形不固定为玄冬楷书，而是跟随全局内容字体设置动态切换。
- 用户于 2026-08-22 明确纠正：暗酒红不是目标，关键是金属铭牌上被铭刻/压印的题字质感。

## 3. 当前源码事实

- `NOTEBOOK_MODEL_SPEC.hardware.plateThickness` 为 `0.034`，铭牌顶面约为局部 `y=0.017`。
- 当前动态铭刻表面位于局部 `y=0.018`，使用 `PlaneGeometry(1.08, 0.22)`，限制在牌体平坦顶面内。
- `src/scene/nameplate-text.ts` 按纸页宋体、玄冬楷书、随峰体或志莽行书生成三张 `2048×512` CanvasTexture：轻微色调图、凹凸图和粗糙度图。
- 铭刻材质设置 `bumpMap`、`bumpScale = 0.005` 和 `roughnessMap`；凹槽法线与粗糙度会随场景光照变化，不再使用固定方向的彩色阴影。
- 牌体在 `create-notebook-model.ts` 中由 `1.12 × 0.38 × 0.034` 的圆角板构成。牌体和动态铭刻表面都使用 `material-library.ts` 导出的 `BRASS_MATERIAL_PARAMETERS`，共享黄铜色、金属度、粗糙度、清漆和环境反射参数。
- `NotebookObject` 等待字体加载后替换铭刻 Mesh，并取消过期异步结果；`disposeNameplateText()` 释放三张纹理、材质和 geometry。
- 玄冬楷书、随峰体和志莽行书的生产字体资源及 SIL OFL 1.1 来源/许可证记录保存在 `public/fonts/`。

## 4. 目标与非目标

### 4.1 目标

- 使用当前全局内容字体渲染中英文混合标签，支持纸页宋体、玄冬楷书、随峰体和志莽行书动态切换。
- 使用 2048×512 抗锯齿纹理，加入凹刻阴影和边缘高光。
- 将文字面放在铭牌顶面高度附近，避免悬浮。
- 在标签替换时释放 CanvasTexture、geometry 和 material。
- 让笔画随视角和场景光线产生凹槽侧壁高光、槽底暗部和轻微粗糙度差异。
- 以黄铜自身的明暗变化为主，颜色只允许作为非常克制的槽底氧化，不把暗酒红固化为字体色。

### 4.2 非目标

- 不引入 CSG 布尔切割或新的 WebGL Canvas。
- 不改变 IndexedDB v4、入口、12 字符限制和本子动画。

## 5. 方案说明

### 5.1 推荐方案：动态铭刻表面贴片

继续用 Canvas 按当前全局内容字体排版，以支持中英文混排、最多 12 字符和四种字体动态切换，但不再直接绘制固定阴影/高光颜色。Canvas 先生成灰度字形遮罩，再派生以下贴图：

1. **高度/凹凸图**：牌面为基准高度，笔画中心形成浅槽，边缘以窄渐变形成斜切刀口。由 `bumpMap` 在着色阶段改变笔画附近的表面法线，让高光方向随场景灯光和相机变化。
2. **粗糙度图**：牌面维持现有黄铜粗糙度；刀口略光滑，槽底略粗糙，避免整行文字像同一块高亮油漆。
3. **克制的色调图**：默认保持黄铜同色，只在槽底加入轻微棕黑氧化或积垢，不采用暗酒红等独立字体色。
4. **全牌细纹**：在顶面加入强度很低、方向一致的拉丝/抛光纹，使刀口高光有稳定参照；细纹必须服从黄铜材质，不能读成木纹或噪点滤镜。

运行时使用一个紧贴牌体顶面、尺寸受控的表面 Mesh 承载动态贴图，其基础色、金属度、环境反射和清漆参数与牌体黄铜保持一致。视觉上它应被读成同一块金属的顶面，而不是另一张透明文字贴纸。建议视觉深度约为本子局部单位 `0.003–0.006`，刀口宽度在最终贴图上约 `1–2px`；具体数值以近景不破字、远景仍可辨认为准。

### 5.2 备选方案

| 方案 | 表现 | 成本与限制 | 结论 |
| --- | --- | --- | --- |
| A. 凹凸图 + 粗糙度图 | 光照可沿笔画形成真实方向变化；动态中英文稳定 | 近距离没有真实轮廓切口，参数需防止过度浮雕 | **推荐本轮实施** |
| B. 浅凹几何 + 贴图混合 | 极近景层次更强，可补少量实际视差 | 字形轮廓网格、资源释放和字符切换更复杂 | 仅在 A 近景仍不足时追加 |
| C. TextGeometry / CSG 真切割 | 几何上真实挖槽 | 中文字体轮廓复杂、运行时切换成本高，容易出现布尔拓扑和性能问题 | 当前不采用 |

第一轮的固定三色阴影/高光实现作为被替代方案保留在实施历史中，不再作为第二轮最终表现。

## 7. 风险、边界与回退

| 风险 | 发生条件 | 影响 | 缓解与回退 |
| --- | --- | --- | --- |
| 字体加载慢 | 首次打开桌面 | 初帧暂时使用字体回退 | `font-display: swap`，字体加载后刷新场景纹理 |
| 纹理仍显得平 | 凹凸强度过低、主光过于正面或远景像素不足 | 刻字层次不明显 | 以近景斜视验收凹槽法线；微调深度、刀口宽度和环境反射，不回退到固定彩色高光 |
| 看起来像浮雕而非凹刻 | 高度图极性反转或强度过大 | 题字从牌面凸起 | 自动测试固定凹凸极性；浏览器从左右斜角确认槽底低、刀口高 |
| 动态表面边界可见 | 顶面材质参数与牌体不一致或尺寸越过倒角 | 像覆盖了一块矩形补丁 | 复用同一组黄铜参数，表面限制在平坦顶面内，并在近景检查四边 |
| 细笔画糊成黑块 | 槽深、氧化或粗糙度差异过强 | 玄冬楷书失去笔锋 | 下采样后限制刀口宽度与槽底暗化；用中英混合最长文本测试 |
| 纹理频繁重建泄漏 | 用户反复保存不同标签 | GPU 资源增长 | 在替换和卸载路径显式释放所有 CanvasTexture、material 与 geometry，并写资源释放测试 |
| 字体授权误用 | 资源被替换或分发说明丢失 | 合规风险 | 保留 SIL OFL README 和来源信息 |

- 持久化与恢复：修改铭牌后重新打开页面，确认 IndexedDB 标签恢复后重新生成完整材质贴图。
