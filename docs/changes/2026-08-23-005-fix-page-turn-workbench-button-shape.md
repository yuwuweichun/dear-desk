## 1. 给阅读者的结论

问题来自真实日记页与翻页动画快照使用了不同的按钮圆角：真实“前往贴纸工作台”按钮继承 `animal-island-ui` 的 `50px` 胶囊圆角，动画快照中的替身却在项目 CSS 中单独写成 `8px`。翻页层出现时，两种轮廓直接切换，于是产生截图中的椭圆变方形跳变。

建议只统一这两个视觉表面的圆角约束，让动画快照从出现到消失都保持与静止页相同的椭圆轮廓；不改变按钮命令、页面内容、翻页时长或 `page-flip` 生命周期。

## 2. 用户需求

- **用户原始要求**：贴纸工作台按钮正常是椭圆，翻页过程中变成方形，需要消除该跳变。
- **Codex 解释**：翻页动画中的只读按钮快照应保持静止页按钮的胶囊轮廓，前后状态不能出现可见的圆角突变。
- 用户提供的两张截图分别显示静止态椭圆按钮与翻页中近方形按钮，作为本任务的视觉问题证据。

## 3. 当前源码事实

- `src/features/journal/JournalPage.tsx` 的 `JournalStickerPage` 使用共享 `Button` 渲染真实“前往贴纸工作台”按钮，并附加 `journal-sticker-workbench-button` 类。
- `src/ui/Button.tsx` 把该按钮交给固定版本 `animal-island-ui` 的 `Button`；其已安装样式为普通按钮声明 `border-radius: 50px`。
- `src/features/journal/PageTurnSheet.tsx` 不克隆真实 React 按钮，而是在 `createStickerPage()` 中创建不可交互的 `div.page-turn-snapshot-action`，文本为“贴纸工作台”。这是 `page-flip@2.0.7` 动画层中的只读视觉快照。
- **实施前源码基线**：`src/styles.css` 曾为 `.page-turn-snapshot-action` 显式声明 `border-radius: 8px`。其高度、边框、背景、颜色和阴影近似真实按钮，但圆角明显不同；`src/features/journal/PageTurnSheet.test.tsx` 当时只覆盖四张快照的日期与左右页排序。
- **当前源码事实**：`src/styles.css` 现在通过同一条选择器把真实按钮与快照替身统一为 `50px`；`PageTurnSheet.test.tsx` 同时确认两个方向各生成两项工作台动作替身。
- **已验证判断**：截图中的轮廓跳变由动画快照的 `8px` 圆角替换真实按钮的 `50px` 圆角直接造成；修复后双视口、双方向的真实计算样式均为 `50px`，无需改动 `page-flip` 几何或状态结算链路。

## 4. 目标与非目标

### 4.1 目标

- 翻页开始、进行和结束时，贴纸工作台按钮始终保持椭圆胶囊轮廓。
- 让真实按钮和只读动画快照共享明确的圆角视觉合同，避免后续一侧单独修改再次分叉。
- 增加针对快照按钮标记的自动回归检查，并在桌面端和移动端实际翻页确认无跳变。

### 4.2 非目标

- 不改变“前往贴纸工作台”的点击行为、文案或启用条件。
- 不调整日记纸页、日期标签、贴纸画布、翻页方向、时长、阴影或折页几何。
- 不修改 `page-flip` 依赖版本，不增加 Canvas/WebGL，也不改持久化数据。
- 不把动画快照变为可交互按钮。

## 5. 方案说明

在日记样式中为真实工作台按钮与 `.page-turn-snapshot-action` 建立同一个胶囊圆角声明，使用与当前共享按钮实际样式一致的 `50px`。删除快照现有的 `8px` 特例，其余快照样式保持不变。

这种修复直接作用于发生分叉的视觉边界，同时保留动画快照与真实业务 DOM 的隔离设计。不会为了一个静态轮廓问题接管第三方按钮 DOM，也不会触碰翻页引擎计算。

## 7. 风险、边界与回退

| 风险 | 发生条件 | 影响 | 缓解与回退 |
