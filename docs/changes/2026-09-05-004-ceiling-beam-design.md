## 1. 给阅读者的结论

最终采用克制的浅色托盘吊顶：高位中央顶面为暖象牙色，墙面为概念图中的暖橄榄灰，四周使用加宽的连续下沉边界，并在房顶与墙面接缝增加双层收口线。不使用中央十字假梁。

## 2. 用户需求

用户原始要求：当前房间顶面单调，希望使用现实生活中的房间装修设计，让用户一眼看出这是房顶，并在当前项目中实现。

Codex 解释：为现有非交互顶面增加固定的、不可持久化的建筑装饰；不把房间扩展为通用装修系统。

## 4. 目标与非目标

### 4.1 目标

- 增加加宽的四周连续下沉边界与墙顶双层收口，形成可辨识的书房托盘吊顶层次。
- 墙面与顶面颜色按确认概念图分别调整为暖橄榄灰和暖象牙色。
- 使用现有 Three.js、单 Canvas 和房间模型生命周期；所有新增表面保持不可交互。
- 保持房间尺寸、相机边界、墙面贴纸、持久化数据和背景开关语义不变。

### 4.2 非目标

- 不提供用户自定义吊顶、灯光控制、装修编辑器或新持久化字段。
- 不新增第二个 WebGL Canvas、依赖、自由走动能力或真实建筑物理。

## 5. 方案说明

概念图 `docs/assets/concepts/study-room-tray-ceiling.png` 是经过当前书房壳体约束后的视觉参考：没有书架、挂画、窗帘、吊灯或中央十字假梁。房间工厂保留完整高位顶面作为背景隔离面，并用一个四实例 `InstancedMesh` 形成连续下沉的四周边界；其下沉量为 `0.38`、边界宽由首轮 `0.88` 扩大到 `2.4`。另一个八实例网格在墙顶接缝形成主收边与外伸压条。概念图取色用于约束墙面、顶面和收边基础色；顶面继续只承担视觉和背景遮挡，不增加交互。
