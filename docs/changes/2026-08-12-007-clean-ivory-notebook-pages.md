## 1. 给阅读者的结论

当前打开后的 DOM 双页外框是明亮薄荷青，与 3D 本子的墨绿色封面不一致；DOM 纸页和 3D 打开页也都绘制了横线。建议把双页外框同步为封面使用的墨绿 `#173f35`，把纸面统一为象牙白 `#fffbe7`，同时移除两条渲染路径中的横线。

完成后，用户从 3D 开本过渡到可书写双页时会看到一致的墨绿包边和纯净象牙白纸面。中缝阴影、纸页边缘与轻微纸张明暗继续保留，用于表达装订和层次，但不再作为横线或彩色装饰出现在正文区域。

## 2. 用户需求

**用户原始要求：** “本子内页边框颜色同步为墨绿，内页为象牙白，不要横线，纯净内页”。

**Codex 解释：**

- “同步为墨绿”指 DOM 双页本子的外侧包边与当前 3D 墨绿封面使用同一主色 `#173f35`，深色落边可沿用封面暗色 `#0e2d27` 表达厚度。
- “象牙白”沿用当前 3D 材质与 DOM token 已共同使用的 `#fffbe7`，不另引入新的近似白色。
- “不要横线”同时覆盖 DOM 页面 `::before` 的重复横线和 Three.js 打开页的 `page-rules` 实例，避免开本转场前后不一致。
- “纯净内页”不删除日期、正文、编辑器和贴纸等业务内容；只移除纸张自身的横线与非必要底纹，保留可读性所需的中缝和克制明暗。

## 4. 目标与非目标

### 4.1 目标

- 把 DOM 双页本子的外侧包边从薄荷青同步为 3D 封面墨绿。
- 让 DOM 和 3D 打开页均以统一的象牙白为纸面主色。
- 删除 DOM 与 3D 内页横线，形成纯净内页。
- 保持桌面端与移动端的阅读、书写、翻页和贴纸操作不变。

### 4.2 非目标

- 不改变封面比例、装订结构、开合枢轴或镜头路线。
- 不改变日期、正文、编辑器、贴纸、翻页命中区或外置命令控件。
- 不改变数据模型、IndexedDB schema、状态所有权或公共接口。
- 不移除中缝阴影、页缘层次和纸张材质所需的轻微明暗。

## 5. 方案说明

以现有 `SCENE_PALETTE.notebookCover` / `notebookCoverDark` 为颜色事实，把 DOM `.journal-spread` 的外框、底色和厚度阴影改为相同墨绿家族，并移除当前点阵装饰。纸面继续使用 `--paper: #fffbe7`，左右页渐变只保留靠近页缘和中缝的轻微明暗，不引入有方向感的重复纹样。

DOM 页面删除 `.journal-page::before` 的横线背景。Three.js 模型删除 `createPageRules` 及左右页对这些实例的挂载和节点暴露；页面 slab、top page 和纸口仍使用现有 paper / paperEdge 材质。这样 3D 负责的开合片段和 DOM 负责的正文页面都遵循同一视觉规则。

### 14.1 实施中补充：书脊中缝优化建议

当前截图中的结构称为“书脊中缝”或“装订沟槽”（gutter）。生硬感来自三项叠加：

- `.journal-spine` 使用固定 `30px` 宽度并贯穿整页，轮廓像独立硬条。
- 左右页渐变与 inset shadow 已各自压暗内侧，再叠加中缝后形成三条平行色带。
- 中缝上下直接连接墨绿包边，没有纸张在书首、书尾自然收拢的渐隐。

建议口径：不再表现一根独立“书脊条”，改为一条约 `14–18px` 的柔和装订沟槽。左右页内侧阴影降低范围与不透明度，中缝中心只保留一条窄暗线和两侧柔光，并在上下 `18–24px` 内渐隐。这样仍能读出双页和折口，但不会切断象牙白纸面的连续感。
