## 1. 给阅读者的结论

当前场景同时使用高明度薄荷背景、高饱和青绿桌垫、暖橙木桌和墨绿本子，色相数量和局部饱和度都偏高，导致视觉焦点在桌垫与背景之间分散。建议改为“安静的冷中性背景 + 低彩度自然橡木桌 + 克制的灰绿织物桌垫”，让现有墨绿色本子成为稳定主焦点，同时保留 Dear Desk 明亮、温和、轻拟物的性格。

V2.0 已复用现有单 Canvas、程序化 PBR 纹理与材质库完成实施；本子颜色、几何、交互、相机、灯光、贴纸范围和持久化状态均未改变。

## 2. 用户需求

- **用户原始要求**：重构背景色，桌子、桌垫的颜色与纹理；本子的颜色不变。
- **用户原始要求**：从符合整体配色的角度提出视觉逻辑，可参考 Google 与 Apple 的规范。
- **Codex 解释**：重点不是换一组孤立色值，而是建立背景、承载面、工作面、主物件的层级关系，并用材质粗糙度、纹理尺度和对比控制支持该层级。
- **验收意图**：本子应比桌垫和桌面更先被注意；桌面仍有自然木材识别度；桌垫仍能被识别为织物；整体在桌面端和移动端均不发灰、不刺眼、不丢失轮廓。

## 3. 当前源码事实

- `src/scene/models/material-library.ts` 的 `SCENE_PALETTE` 集中定义背景、木桌、桌垫、本子、纸张与点缀色。
- 同一文件的 `sampleSurfaceChannels()` 为 `wood`、`cloth`、`kraft`、`paper` 生成确定性的 albedo、AO、height 与 roughness；当前木纹以暖橙棕为基底，布纹以高饱和青绿为基底。
- `createModelMaterialLibrary()` 将木、布、本子和纸分别绑定独立纹理集合；本子使用 `kraft` 通道及 `notebookCover` / `notebookCoverDark`，可在不修改本子材质的前提下独立调整木与布。
- `src/scene/DeskScene.tsx` 使用 `SCENE_PALETTE.background` 作为 WebGL 场景背景，并复用现有单个 R3F Canvas。
- `src/scene/models/model-factories.test.ts` 对现有色值、材质分离、纹理通道、资源释放和模型预算有自动断言。
- **合理推断**：当前薄荷背景 `#c9f0e5` 与桌垫主色 `#0cc0b5` 同属青绿色，构成大面积同色相竞争；暖木与珊瑚点缀又引入高色温对比，使墨绿本子的焦点优势不足。该判断需在实现阶段用桌面与移动端截图验证。

## 4. 目标与非目标

### 4.1 目标

- 建立背景、桌面、桌垫、本子的清晰视觉层级，本子颜色完全不变。
- 让木纹与织物纹理在近景可辨、远景不形成噪点或摩尔纹。
- 保持现有程序化、确定性、离线可用的 PBR 材质路径和资源预算。
- 为色值、材质边界与纹理特征增加相称的自动断言，并完成桌面与移动端视觉验收。

### 4.2 非目标

- 不修改本子封面、书脊、纸张的颜色、纹理、粗糙度或几何。
- 不改变桌子或桌垫几何、贴纸命中范围、相机、灯光、交互和动画。
- 不增加外部贴图库、运行时网络依赖、第二个 WebGL Canvas、主题切换或用户配色设置。
- 不调整 DOM 界面主题；若视觉验证发现明显冲突，将另立任务，不在本次扩围。

## 5. 方案说明

最终采用“中性空间、暖承载面、冷工作面、深色焦点”的四层逻辑：背景使用冷灰；桌子用中深胡桃木提供稳定重量；桌垫用蓝灰区分工作区域；本子维持现有墨绿色成为最深、最稳定的视觉锚点。珊瑚点缀仅保留在小面积功能细节，不参与大面积竞争。

当前批准并已实施的 V2.0 为：背景 `#D5DAD8`；木桌主面/框架/嵌板 `#927054`、`#5F4939`、`#AA8768`；桌垫工作面/bumper `#73858A`、`#4C5E63`；本子继续使用 `#173F35` / `#0E2D27`。设计逻辑参考 Google Material 3 对 surface 层级、角色化色彩与可访问对比的原则，以及 Apple Human Interface Guidelines 对克制用色、层级、对比和材质一致性的原则；实际产品截图和用户判断优先于抽象规范。历史 V1 Warm Studio 已被否决，精确值和禁用条件见第 5.1 节。

实现上把 palette token 设为表面基色的唯一所有者，木/布程序化 albedo 只提供中性明暗变化；保留 16 张现有纹理、UV、灯光和渲染设置。本子 `kraft`、纸张采样与材质参数全部冻结，并以固定坐标样本进行自动回归保护。

## 7. 风险、边界与回退

| 风险 | 发生条件 | 影响 | 缓解与回退 |
| --- | --- | --- | --- |
| 场景过灰或失去亲和力 | 背景和桌垫同时降彩过度 | 产品显得冷淡、物体轮廓变弱 | 保留暖木与小面积珊瑚；按截图比较回退单组 token |
| 本子焦点仍不突出 | 桌垫与本子明度或色相过近 | 主入口识别变慢 | 桌垫保持更高明度、更低饱和度；验证主体与承载面边界 |
| 程序化纹理形成噪点/摩尔纹 | 高频幅度过强或 mip 下仍显著 | 移动端和远景闪烁 | 降低高频 albedo/height 幅度，保留 mipmap 与 anisotropy，跨机位验证 |
| 木材失去材质识别度 | 颜色过于均匀或纹理方向不自然 | 桌面像塑料 | 保留纵向多尺度木纹，仅控制色差与粗糙度，不改 UV/几何 |
| 无意改变本子 | 共用 palette 或纹理分支被连带修改 | 违反用户硬约束 | 自动锁定两个本子色值、`kraft` 采样与本子材质参数；Git 差异逐项核对 |

回退以恢复 `SCENE_PALETTE` 中背景/木/布 token、`wood` 与 `cloth` 采样公式及相关材质参数为单位；不涉及数据回滚。
