### 4.1 目标

- 核实 Sticker Forge 的实际功能、公开 API、包管理方式、许可证和浏览器支持。
- 设计它与 React、React Three Fiber、Zustand、Dexie 及单 WebGL 画布的真实调用链。
- 明确文字贴纸、图片贴纸、编辑、放置、移动、旋转、删除和恢复分别由谁负责。

### 4.2 非目标

- 本记录不批准任何业务源码、依赖或数据库修改。
- 不假定 Sticker Forge 已直接兼容当前 Three.js/R3F 架构。
- 不在未核实许可证、版本和 API 前承诺具体数据结构。
