## 1. 给阅读者的结论

截图中的主要问题是桌板真实轮廓采样不足，不是木纹贴图分辨率不足。桌板使用程序化圆角挤出几何，但当前没有传入专用分段值，因此沿用 `10` 段默认值；近距离、高反差边缘和连续高光会把各段明显显示出来。

建议先只把桌板圆角曲线提高到 `32` 段，并保留桌垫已经采用的 `48` 段不变。该改动直接改善剪影且成本很低。若桌板侧缘在实机截图中仍出现明显竖向高光分带，再在不抹平桌面、倒角和侧壁边界的前提下补充受控平滑法线；不把法线调整作为未经验证的默认改动。

## 2. 用户需求

- 用户原始要求：对桌子模型进行细节处理，减少桌板圆角肉眼可见的多边形，使其视觉更光滑。
- Codex 解释：本次只处理桌板圆角的轮廓分段与必要的法线连续性，不改变桌板尺寸、厚度、圆角半径、木纹、颜色、桌腿、抽屉、桌垫或镜头。
- 验收意图：用户提供的近距离视角下，桌板前角不再读成连续折面，同时保持桌板原有薄板比例和清晰倒角。

## 3. 当前源码事实

- 产品调用链为 `src/scene/DeskScene.tsx` -> `createModelMaterialLibrary(...)` -> `createDeskModel(materials, { pass: 'optimization-pass' })` -> `createRoundedPlateGeometry(...)` -> `createRoundedPanelGeometry(...)` -> Three.js `ExtrudeGeometry`。
- `src/scene/models/create-desk-model.ts` 的桌板创建只传入尺寸、平面圆角半径与 `0.09` 倒角，没有传入 `curveSegments`。
- `src/scene/models/geometry.ts` 中 `createRoundedPanelGeometry` 的 `curveSegments` 默认值为 `10`，并设置 `bevelSegments: 2`；几何创建后已经执行 `computeVertexNormals()`。因此重复调用普通顶点法线计算不是充分修复。
- `src/scene/models/model-specs.ts` 固定桌板为 `12 x 8`、厚 `0.34`、圆角半径 `0.52`，上表面世界高度保持 `0.05`。
- `src/scene/models/create-desk-mat-model.ts` 已对桌垫圆角显式使用 `48` 段，且 `model-factories.test.ts` 会验证这一事实；桌板当前没有对应的分段回归断言。
- `src/scene/models/model-specs.ts` 给整个模型设定 `80,000` 三角面预算，`createDeskModel` 会在运行时测量并拒绝超预算模型。
- 合理推断：截图中外轮廓的折线主要由桌板的 `10` 段圆角采样造成；侧缘的竖向色带还可能包含挤出侧壁逐面法线与木材高光共同放大的效果，需要实现后的近景截图确认。
- 文档与源码未发现会阻止本次方案的冲突。

## 4. 目标与非目标

### 4.1 目标

- 提高桌板平面圆角的几何采样，使近景剪影明显更圆滑。
- 保持桌板顶面、倒角和侧壁之间的形体层次。
- 用自动测试锁定桌板专用分段，并确认模型仍在资源预算内。
- 在桌面与移动端产品场景中验证视觉结果，桌面端增加用户截图对应的近距离斜角检查。

### 4.2 非目标

- 不改变桌板尺寸、厚度、平面圆角半径或世界坐标。
- 不重做木纹贴图、材质颜色、灯光、阴影或相机系统。
- 不细化桌腿、抽屉、围板、桌垫或本子。
- 不引入细分曲面、建模依赖、第二个 WebGL Canvas 或持久化字段。

## 5. 方案说明

第一步在 `DESK_MODEL_SPEC.tabletop` 中增加明确的圆角分段规格 `curveSegments: 32`，并由 `createDeskModel` 传给桌板几何。`32` 段足以把当前 `10` 段的可见折线显著压低，同时比照搬桌垫的 `48` 段更克制；桌板只有一个网格，新增三角面相对 `80,000` 总预算很小。

第二步运行模型测试、资源测量和产品近景视觉验收。若剪影已平滑但侧壁仍存在明显逐面高光，才对圆角挤出帮助函数增加可控、带折角阈值的法线平滑方式，并让桌板显式启用；阈值必须保留顶面、倒角与侧壁边界。若 `32` 段仍能看出轮廓折线，可在同一已批准范围内上调到 `48`，但以视觉证据和预算结果为准。

不建议只降低材质高光或提高抗锯齿：材质只能掩盖分面，抗锯齿只处理像素边缘，两者都不会改变当前真实的多边形剪影。
