## 1. 给阅读者的结论

本子已经正向、居中并放平，近处相机也与桌面中心轴对齐。用户最终否决闭合时位于本子中央的粉色书签，并将封面粉色角标与两颗圆钉识别为不需要的“猪鼻装饰”。最终结果是完整删除 3D 与 DOM 书签、封面角标、装饰圆钉及粉色书脊装饰，不增加替代物；本子的中性软壳、页芯、开合和 DOM 日记功能继续保留。

## 2. 用户需求

**用户原始要求：** “本子现在是斜着放的，改为正着放置”。

**用户补充要求：** “居中，除了水平斜角还存在竖直斜角？”

**用户最终补充：** “删除竖直斜角”。

**用户截图验收补充：** “近处视角里，桌子是歪的，修复为正”。

**用户本轮验收补充：** “本子粉红色的书签的位置不对”。

**用户最终视觉决定：** “？谁家书签闭合时位于本子中央啊，本子上的猪鼻装饰又是什么，删除吧，删除书签，这个粉色猪鼻装饰也删除”。

**Codex 解释：** “正着”指桌面平面内不再旋转，即本子封面边缘与桌垫边缘平行；“居中”指本子外层组的 `X/Z` 中心对齐桌垫中心；“删除竖直斜角”指外层组在所有阶段保持 `Z = 0`。模型内部封面铰链旋转仍负责开本子，不属于要删除的整体斜角。

用户截图中的桌面倾斜不是桌子模型发生旋转，而是近处相机 `position.x` 与 `target.x` 不一致造成的横向透视：桌面端为 `0.2 -> 0`，移动端为 `0.1 -> 0`。最终修正将两端近处相机的 `position.x` 归零，使相机与目标共用 `X = 0` 中心轴；保留高度、前后距离、target 高度和 FOV。

书签问题最初来自旧模型的闭合轨迹：打开锚点位于中缝 `X = -1.46`，尾部却在闭合时横向漂到接近中央的 `X = 0.08`，导致整条书签在封面下方形成斜带。后续曾尝试闭合时居中、开盖时平移到中缝，但用户最终明确否决书签本身；这些定位方案均已被完整删除书签的决定替代。

视觉复核还确认左侧三段粉红凸起是软壳模型新增的珊瑚书脊环；它们已经删除。封面角标及其两颗圆形装饰钉也因形成“猪鼻”观感而删除。打开后的 DOM 日记同样不再渲染书签，仅保留中性书脊阴影。

## 3. 当前源码事实

- `src/scene/NotebookObject.tsx` 的本子外层 `<group>` 使用固定 `rotation={[0, -0.16, -0.12]}`。
- Three.js Euler 的第二项是绕竖直 `Y` 轴的桌面平面内朝向；当前 `-0.16` 造成斜放。
- 第三项 `Z = -0.12` 由 `useFrame` 在桌面态维持，并在打开流程中收敛到 `-0.02`；用户已明确要求删除这个外层竖直斜角。
- 本子的开合由模型内部 `coverPivot.rotation.z` 和 `setOpenProgress()` 驱动；外层水平朝向与开合状态机相互独立。
- `DESK_MAT_MODEL_SPEC.position = [0, 0.055, 0.2]`，而原本子 `rootPosition = [-0.65, 0.34, 0.25]`，因此本子中心相对桌垫中心向左 `0.65`、向后 `0.05`。
- 当前工作区已包含 `DD-20260812-001` 对 `NotebookObject.tsx` 的 hover 高度修改，本任务必须保留该修改。

文档、源码与测试没有冲突；现有测试尚未约束本子桌面朝向。

## 4. 目标与非目标

### 4.1 目标

- 将本子桌面平面内的固定朝向从 `Y = -0.16` 改为 `Y = 0`。
- 将本子外层中心对齐桌垫中心，即 `rootPosition` 改为 `[0, 0.34, 0.2]`。
- 删除外层 `Z` 倾角及其逐帧倾角动画，使整体在所有阶段保持放平。
- 保留高度、hover、点击命中区和模型内部封面开合动画。
- 增加自动测试，防止后续再次无意引入斜角。
- 删除 3D 书签、封面粉色角标、两颗装饰圆钉和粉色书脊装饰，并清理对应几何、材质、socket 与 runtime 契约。
- 删除打开后 DOM 日记的粉色书签及响应式样式，不增加替代装饰。

### 4.2 非目标

- 不修改桌子、桌垫或本子保留部分的几何与材质。
- 不改变三个相机预设；除删除 DOM 书签外不调整日记布局。
- 不改变状态、持久化、贴纸坐标或单 Canvas 所有权。

## 5. 方案说明

把桌面姿态集中到 `NOTEBOOK_MODEL_SPEC.deskRotation`，值设为 `[0, 0, 0]`，并将 `rootPosition` 改为 `[0, 0.34, 0.2]`，与桌垫 `X/Z = [0, 0.2]` 对齐。`NotebookObject` 从规格读取这些值，并删除外层组逐帧调整 `Z` 的逻辑。最终视觉修正直接从模型工厂和 DOM 中删除被否决的粉色装饰，同时删除仅供其使用的规格、几何、材质和 runtime 引用，避免残留无效契约。
