## 5. 方案说明

使用 `$imagegen` 内置模式，按 `stylized-concept` 生成一张项目内概念资产。提示采用“环境 → 主体 → 结构与材质 → 构图 → 光照 → 约束”的顺序：

1. 环境是一间尺度亲密的简洁书房，包含清楚的后墙、侧墙、木地板、单扇窗和少量开放书架。
2. 主体复述当前程序化模型：中深胡桃木三抽屉书写桌、橄榄苔绿织物桌垫、墨绿布面本子和克制黄铜细节。
3. 风格为明亮、温和、轻拟物的程序化 3D 概念渲染，几何轮廓清楚，材质层次低对比，不追求摄影写实。
4. 使用主三分之四广角但避免夸张畸变；桌子完整可见，墙—地交界、窗、书架和房间角落可读。
5. 柔和日间窗光配合暖中性室内反射，背景对比和饱和度低于桌面主体。
6. 明确避免人物、文字、标志、水印、第二张桌子、椅子遮挡、密集装饰、纯氛围雾和无法解释的结构。

生成后由 Codex 检查主体、构图、结构可读性、色彩兼容和禁用项。若候选满足要求，就复制到项目目录并展示；若存在单一明显缺陷，只针对该缺陷迭代一次并如实记录。

用户验收修订采用精确编辑：以 `room-concept-v1.png` 为 edit target，保持相机、画幅、房间比例、窗户、墙面、墙角、踢脚线、木地板、日间窗光、阴影方向与整体色调不变；只移除桌子、桌垫、本子、书架、书、画框、植物和其他物件，并用连续墙面与地板自然补齐被遮挡区域。编辑结果不得新增门、家具、灯具、装饰或文字。

## 7. 风险、边界与回退

| 风险 | 发生条件 | 影响 | 缓解与回退 |
| --- | --- | --- | --- |
| 房间好看但难建模 | 遮挡多、透视含糊、结构不闭合 | 后续大量猜测 | 提示强调结构可读和克制陈设；不通过则拒绝候选 |
| 房间抢焦 | 背景更亮、更饱和或细节过密 | 桌面入口变弱 | 背景降对比与饱和度，桌子保持中心和最高材质层次 |
| 与当前模型不融洽 | 生成结果变成写实、极简现代或卡通玩具 | 接入后视觉割裂 | 明确轻拟物程序化 3D、当前材料与色彩层级 |
| 图像暗示完整房间系统 | 画面包含可探索空间或复杂功能 | 超出 MVP | 限定固定座位附近的受控环境，不画自由探索动线 |
| 生成图改变现有桌子身份 | 桌型、比例、桌垫或本子被重新设计 | 后续无法复用源码 | 提示锁定三抽屉桌、连续桌垫和单册本子；差异必须标为概念近似 |
