## 1. 给阅读者的结论

建议增加一个只在桌面空闲状态出现的实时场景调色器。用户可以分别修改环境、桌面结构、桌垫和本子外壳等九类表面，并复制当前 HEX 配置；刷新页面后恢复 V2 运行回退值，不把实验色写入产品数据。

这个面板不是在假设“继续调色就能救模型”。它的价值是建立受控实验：若大量颜色组合仍无法改善轮廓、比例、体块或材质观感，就有更充分证据把下一步转向模型重做，而不是继续盲目生成整套配色。

## 2. 用户需求

- **用户原始要求**：V1-V10 全部不通过，并怀疑模型造型本身可能是问题根源。
- **用户原始要求**：提供开放编辑颜色的面板，至少覆盖本子外壳、桌垫、桌子、桌腿和环境背景。
- **Codex 解释**：把源码中真实独立的材质角色完整暴露，并补拆当前共用材质的桌腿/支撑，使每个控件都对应明确表面。
- **体验意图**：改色即时生效；用户可以自由探索不同色系，不再由 Codex 预先限制为少数完整方案。
- **范围变化**：此前“本子颜色不变”的约束被本次明确请求更新为“本子外壳可编辑”；纸张颜色与纹理仍保持不变。

## 4. 目标与非目标

### 4.1 目标

- 提供环境背景/fog、桌面、桌框/围板、桌腿/支撑、桌面嵌板、桌垫工作面、桌垫垫体/滚边、本子外壳、本子深色书脊/接缝九个独立颜色控件。
- 每项同时提供原生颜色色块和可编辑 HEX 文本；只接受规范 `#RRGGBB`，无效文本不更新场景。
- 颜色在输入后实时投影到现有单一 R3F Canvas，不重建页面或丢失当前镜头。
- 提供恢复 V2 回退值、复制当前 JSON/HEX 配置、打开/关闭面板三类命令。
- 桌面端使用紧凑右侧工具面板；移动端使用全宽底部抽屉，避免遮挡现有主要命令。
- 只在本子、贴纸工作流和桌面贴纸选择均为空闲时显示入口和面板。

### 4.2 非目标

- 不承诺仅靠颜色修复模型，不在本任务调整几何、比例、轮廓、UV、纹理、PBR、灯光、曝光、相机或动画。
- 不做正式主题系统、预设管理、命名、分享链接、导入、账号同步或颜色历史撤销栈。
- 不把试色写入 IndexedDB、Zustand、localStorage、URL 或服务端；刷新即恢复当前 V2 运行回退值。
- 不修改纸张、贴纸、珊瑚 tab、DOM 产品主题或 Sticker Forge 配色。
- 不增加第二个 WebGL Canvas。

## 5. 方案说明

`ProductApp` 持有一份组件级 `SceneColorConfig`，用 V2 回退值初始化并作为 prop 传给 `DeskScene`。调色器修改该普通可序列化对象；`DeskScene` 继续拥有 Three.js 材质，只把配置投影到对应材质颜色和 background/fog。这样 React 状态是实时颜色事实，Three.js 仍只是视觉投影，符合现有本地状态边界。

面板按“环境 / 桌子 / 桌垫 / 本子”分组。每一行包含表面名称、颜色输入与 HEX 输入；工具栏使用 Palette、RotateCcw、Copy、X 等 lucide 图标并提供可访问名称。复制内容包含版本标识和九个角色键，便于后续把用户满意结果固化为新方案，也便于证明哪些颜色实验仍无法改善模型。

桌腿独立控制需要新增专属 `deskLegs` palette 字段和材质。板式支撑使用该材质；桌框前后围板与下横梁继续使用 `deskFrame`；支撑嵌板继续独立使用 `deskInset`。这是一项材质所有权拆分，不改变几何节点、碰撞体或 draw call。

### 6.2 上下游与跨模块影响

- 上游：`ProductApp` 是唯一颜色状态所有者，调色面板只发出颜色对象更新、重置和复制命令。
- 下游：`DeskScene` 将字符串色值投影到 scene background、fog 和共享模型材质；三个模型工厂不拥有业务状态。
- 渲染：仍为一个 R3F Canvas；改色只更新颜色/必要材质引用，不新增 Canvas、纹理族或持续动画。
- 资源：新增桌腿材质必须加入 `dispose()` 集合并由测试确认释放；不新增纹理，因此 16 张程序纹理预算不变。
- 兼容：现有 `?palette=v1..v10` 开发截图入口继续决定初始值还是被移除，需要实现时以“产品无参数默认 V2、编辑器可重置”为准；不得让查询参数与面板形成两个互相覆盖的状态源。
- 文档：V1-V10 仍完整保存截图和色值并标记全部否决；新面板产生的实验值只有用户明确批准后才获得新版本编号。

## 7. 风险、边界与回退

| 风险 | 发生条件 | 影响 | 缓解与回退 |
| --- | --- | --- | --- |
| 控件很多遮挡场景 | 小屏或面板常开 | 无法同时观察整体与操作颜色 | 移动端底部抽屉可关闭且内部滚动；桌面限制宽高 |
| 输入过程产生无效 HEX | 用户逐字符编辑文本 | Three.js 报错或颜色闪烁 | 文本保留草稿，只有完整 `#RRGGBB` 才提交场景 |
| 桌腿与桌框看似独立但仍联动 | 未拆分共享 `walnutDark` | 诊断结论失真 | 增加专属桌腿材质并测试实际 mesh-material 绑定 |
| 频繁重建材质 | 每次键入都重建整套纹理/材质 | 卡顿或资源泄漏 | 优先原位更新颜色；若沿用重建路径，严格释放并测试 |
| 实验值被误认成产品配置 | 用户刷新或分享截图 | 结果不可复现 | 面板明确显示“临时”；复制 JSON 是唯一导出，不持久化 |
| 颜色仍无法改善视觉 | 模型比例/轮廓是主要问题 | 继续调色浪费时间 | 把结果作为转向模型评审/重构的证据，不继续自动扩展配色 |

回退方式：删除调色器组件和 `DeskScene.colors` 输入，恢复 V2 初始化；桌腿专属材质可重新绑定桌框材质。无持久化迁移和不可逆数据步骤。
