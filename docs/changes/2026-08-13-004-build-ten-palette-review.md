## 4. 目标与非目标

### 4.1 目标

- 建立 V1-V10 十个不可被静默覆盖的配色预设与版本元数据。
- V3-V10 覆盖显著不同的色相家族，而不是只做蓝灰明度变化。
- 为每版保留至少两个相同桌面机位的产品截图：整体关系图与近景材质图。
- 生成一份本地可直接打开、可搜索、可按版本导航、响应式且无障碍的 HTML 对比档案。
- 同步生成一份 Markdown 台账，方便 Git diff、后续代理读取和精确追踪色值。
- 用户未选择前保持 V2 为产品默认；选择后再以同一任务补充验收结论，或在全部否决时保留十版负向证据。

### 4.2 非目标

- 不自动宣布某个版本获胜，不把 V10 当成自然终点或最终默认值。
- 不修改本子、纸张、灯光、曝光、几何、UV、相机、交互、动画、Canvas 数量或持久化数据。
- 不开发面向最终用户的主题选择器、设置页或多主题持久化功能。
- 不为每个候选单独做移动端六机位全量验收；候选比较使用统一桌面视口，最终被选版本再执行完整桌面/移动验证。
- 不恢复 V1 为默认值；V1 只作为已否决历史对照。

## 5. 方案说明

### 5.1 比较原则

十个版本使用同一模型、灯光、曝光、纹理采样、相机位置、视口和页面状态。V2-V10 固定 V2.0 的 PBR 参数，只更换五个大面积角色色：背景、木桌主面、木桌框架、木桌嵌板、桌垫工作面和 bumper。历史 V1 保留其真实旧 PBR，不伪造为新参数下的重渲染，并在文档中明确这一比较边界。

这套控制变量策略可让用户主要判断色相、明度、冷暖和面积关系。若某版确实需要不同 PBR 才成立，应在用户选定方向后新增小版本，而不是在十版初筛中同时混入材质变量。

3. 更新 `DeskScene.tsx`，让背景/fog 和材质库消费同一个已解析 preset，避免背景版本与桌面版本错配。
4. 扩展 `model-factories.test.ts`：验证十个编号唯一、HEX 完整、V1/V2 历史值不变、默认仍为 V2、本子/纸张全版本冻结，以及开发选择入口不会进入持久化。
5. 用 ego-browser 在同一 `1440 × 900` 环境、同一 overview/detail 机位捕获 V1-V10 共 20 张候选图；截图前后核对实际版本标识，杜绝文件名与渲染值错配。
6. 使用 `$bun-html-docs` 创建并验证 `docs/palette-review/index.html`，同时生成 `palettes.md`；把截图存入文档资产目录，不依赖 `/tmp` 或外网。

### 6.1 核心数据结构变化

- 新增只读 `ScenePalettePreset` / `ScenePaletteVersion` 类型和 `SCENE_PALETTE_PRESETS` catalog，生命周期为源码版本，不进入运行时业务状态。
- `createModelMaterialLibrary(options)` 增加可选 palette 参数；无参调用继续产生 V2，与当前调用兼容。
- IndexedDB schema、repository、Zustand store、领域实体与用户持久化数据均不改变；证据是 palette 仅由渲染材质库和 `DeskScene` 消费。

### 6.2 上下游与跨模块影响

- 上游：开发截图查询参数只决定渲染 preset，不写入 URL 之外的任何状态；production build 固定 V2。
- 核心：背景/fog 与 wood/cloth 材质必须共享同一 preset 对象。
- 下游：桌子和桌垫工厂继续消费共享材质实例；本子继续消费固定 token 和 kraft/paper 通道。
- 文档：HTML 和 Markdown 从同一份人工核验后的版本台账生成内容，路径必须通过文档引用检查。
- 性能：preset catalog 只保存小型字符串对象；每次页面仍只实例化当前版本的 16 张纹理和一套材质，不同时加载十套 WebGL 资源。

## 7. 风险、边界与回退

| 风险 | 发生条件 | 影响 | 缓解与回退 |
| --- | --- | --- | --- |
| 十版看起来仍过于相似 | 只改变小幅明度或都使用蓝灰 | 用户无法有效选择 | 按第 5.2 节覆盖八种色系，检查色相距离与真实截图 |
| 截图不可公平比较 | 机位、视口、灯光或状态不同 | 选择受到构图而非颜色影响 | 固定两机位、1440×900、同一灯光和空白数据状态 |
| V1 历史证据被美化 | 用新 PBR 重渲染 V1 | 否决原因失真 | 使用原始 V1 截图并注明旧 PBR 边界 |
| 候选误发布为默认 | 最后截图停留 V10 或 resolver 进入生产 | 用户看到未选择版本 | production 固定 V2；测试默认值；截图完成后重开无参数页面核验 |
| 本子被连带改色 | palette catalog 包含或覆盖 notebook token | 违反硬约束 | notebook/paper 不进入候选差异字段；逐版本自动断言固定值与样本 |
| 文档资产丢失 | HTML 引用 `/tmp` | 后续无法审阅 | 所有截图复制到 `docs/palette-review/assets/` 并运行引用检查 |
| HTML 对比页在移动端过宽 | 并排截图与色值表固定宽度 | 无法阅读 | 移动端改单列；表格/代码仅容器内部横向滚动 |

回退方式：删除候选 catalog、开发截图解析和对比文档，并恢复无参 V2 常量路径；不涉及数据迁移。V1/V2 的历史记录不得因回退删除。
