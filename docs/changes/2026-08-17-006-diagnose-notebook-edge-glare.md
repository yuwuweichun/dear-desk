## 1. 给阅读者的结论

这不是单一的“反光”，而是三种效果叠加。截图前侧最宽、最白的一带主要是暖纸页口朝向主光后发生的高亮/曝光压白，不是镜面倒影；绿色封套边缘的断续白点属于布纹凹凸在掠射角产生的高光走样；连续书壳几何在锐角处共享顶点并统一平均法线，又把本应很窄的边缘高光扩展成了发亮轮廓。

当前场景没有 Bloom、屏幕空间反射或镜面反射后处理，因此不能把白线归因于“反射了桌面或灯具”。PBR 环境贴图和布料 sheen 确实参与了边缘高光，但它们是放大因素，不是截图中整条白色页口的唯一原因。最可疑的材质回归是本子布面 `bumpScale = 0.35`：它比同一材质库中的桌垫布面 `0.004` 高约 87.5 倍，也远高于前一任务记录检查时的 `0.006`，足以让高频织纹在边缘变成闪点。

## 3. 当前源码事实

- 用户截图显示本子页口、封套外缘与右侧装订边出现接近纯白的细亮线，封面主体仍保持深绿色并能看到布纹。
- `src/scene/DeskScene.tsx` 当前使用一盏强度 `2.05` 的暖色投影方向光、一盏强度 `0.42` 的冷色补光、强度 `1.15` 的半球光和强度 `0.42` 的场景环境，并启用 ACES Filmic tone mapping、曝光 `1.04`。
- 主方向光位于 `[-5.5, 10.5, 7]`，截图前侧页口对应的正 `z` 侧面直接朝向光源。页口底色本身为浅色 `#e6dcc4`，虽有 `roughness = 0.96`，漫反射仍会被多盏光累加并经 ACES 映射推近显示白点；高粗糙度只能抑制清晰镜面高光，不能阻止漫反射过亮。
- `SceneEnvironment` 使用 Three.js `RoomEnvironment` 生成 PMREM 环境贴图。它会给物理材质提供环境镜面响应，但场景没有 EffectComposer、Bloom、SSR 或镜面反射材质。
- `notebookCover` 是非金属 `MeshPhysicalMaterial`，使用高频程序化 cloth albedo/AO/height/roughness，另有 `roughness = 0.8`、`sheen = 0.18`、`anisotropy = 0.22` 和 `bumpScale = 0.35`。非金属表面在掠射角仍有 Fresnel 高光，sheen 会进一步突出布料边缘。
- 同一材质库的桌垫布面 `bumpScale = 0.004`，深色桌垫克隆材质为 `0.002`。本子当前的 `0.35` 分别是它们的 87.5 倍和 175 倍；这与截图中绿色边缘的颗粒状亮点相符。
- cloth 高度贴图以约 `size / 12` 与 `size / 14` 的经纬线频率生成；默认纹理尺寸为 `1024`，启用 mipmap、三线性缩小过滤和 anisotropy `8`。过滤能减轻纹理走样，但不能抵消异常大的 bump 强度在掠射角造成的法线变化。
- `createContinuousCaseGeometry()` 用同一圈索引顶点连接封面顶面、垂直边、圆背和端盖，最后对整个 indexed geometry 调用 `computeVertexNormals()`。锐角处没有拆分顶点或显式硬边法线，因此相邻面的法线会被平均；端盖也复用侧面的边界顶点。这会在没有真实圆角宽度的地方制造视觉上的光滑转折，并形成比预期更宽的轮廓高光。
- 截图中没有典型 z-fighting 的交替条纹、摩尔纹或随像素随机切换的两种表面颜色；当前页口层使用相互错开的实例化薄条。深度冲突不是首要原因，但极薄 `0.0045` 高的页层和强对比会加重抗锯齿边缘的颗粒感。
