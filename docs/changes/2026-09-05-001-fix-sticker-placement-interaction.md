## 4. 目标与非目标

### 4.1 目标

- 放置产物后提供明确的“完成”动作以退出调整状态。
- 提供最小可理解的贴纸缩放交互，并在刷新后恢复尺寸。
- 墙面装饰最大支持 `5×`，桌面与日记保持最大 `2×`。
- 桌面贴纸可在桌面顶面允许范围内放置和移动。
- 保持三 surface 创建、移动、旋转、删除与持久化行为不回归。

### 4.2 非目标

- 不新增第二套装饰资产或制作器。
- 不实现自由形变、非等比缩放、图层系统或通用装修系统。
- 不改变墙面窗洞净空、日记日期语义或 Sticker Forge 固定版本。
