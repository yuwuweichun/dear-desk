## 1. 给阅读者的结论

移除 `DeskScene` 中的场景雾，使房间墙体不再因深度雾与背景色混合。该变更只删除雾效果，保留背景色、灯光、四面墙、桌面对象和单 Canvas 边界。

## 2. 用户需求

- 删除场景中的雾。
- 不再使用此前的 `44..82` 雾范围方案。

## 3. 当前源码事实

`DeskContents` 曾在“无材质”和“完整材质”两个渲染分支分别创建 `<fog attach="fog" args={[colors.background, 44, 82]} />`。两处都使用背景色作为雾色，远墙因此可能被混合为背景色。

## 4. 目标与非目标

### 4.1 目标

- 删除两个 fog 挂载点。
- 保留场景背景色和现有灯光，不改变桌面对象坐标或交互。
- 同步产品、架构、HTML 和变更文档，验证无残留 fog 配置。

### 4.2 非目标

- 不改变房间尺寸、墙面颜色、窗洞、相机或材质纹理。
- 不新增交互、家具、持久化数据或 WebGL Canvas。

## 5. 方案说明

直接移除 `DeskContents` 两个 fog JSX 节点。这样墙体最终颜色只由自身材质、法线和灯光决定，背景色只负责清屏，不再参与远近深度混合。

## 6. 预计改动与影响评估

- `src/scene/DeskScene.tsx`：删除两个 fog 节点。
- `docs/product/mvp.md`、`docs/architecture/study-room-shell.md`、`docs/architecture/system-overview.html`、本记录：同步场景无雾事实。
- 不涉及状态、持久化、公共接口、资源所有权或数据迁移。
