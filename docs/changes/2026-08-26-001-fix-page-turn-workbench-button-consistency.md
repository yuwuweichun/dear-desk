## 1. 给阅读者的结论

本次复现显示，翻页动画中的贴纸工作台动作替身虽然仍使用 `50px` 圆角，但没有复用常态按钮的完整 UI：快照是宽约 `92px`、仅显示“贴纸工作台”的纯 `div`，没有 Sticker 图标，也没有“前往”前缀；常态页是真实共享 `Button`，显示图标和“前往贴纸工作台”，宽约 `153px`。翻页层出现时，这两个不同结构直接切换，造成用户截图中的按钮跳变。

拟议修复是让 `PageTurnSheet` 的只读快照动作替身使用与常态按钮一致的文案、图标占位和布局尺寸合同；继续保持快照不可交互，不改变翻页引擎或业务状态机。

## 2. 用户需求

- **用户原始要求**：贴纸工作台按钮在翻页动画时与常态 UI 不一致，出现跳变；此前修复过但问题再次出现。
- **Codex 解释**：翻页动画期间的贴纸工作台按钮必须在轮廓、文案、图标和主要尺寸上与静止态按钮一致，避免动画层替身替换真实按钮时产生可见跳变。
- 用户提供的两张图片仅作为现象证据，不视为额外指令或产品规范。

## 3. 当前源码事实

- `src/features/journal/JournalPage.tsx` 的 `JournalStickerPage` 使用共享 `Button`，类名为 `journal-sticker-workbench-button`，传入 `Sticker` 图标，文案为“前往贴纸工作台”。
- `src/ui/Button.tsx` 将该按钮适配到 `animal-island-ui`，当前真实计算样式为 `border-radius: 50px`，在本地 `127.0.0.1:5164` 桌面验证尺寸约为 `153 × 45px`。
- **实施前事实**：`src/features/journal/PageTurnSheet.tsx` 的 `createStickerPage()` 使用 `appendText(body, 'div', 'page-turn-snapshot-action', '贴纸工作台')` 创建静态替身，不克隆真实按钮，也不创建图标节点；实施后已改为结构化的只读动作替身。
- `src/styles.css` 已由 `DD-20260823-005` 为 `.journal-sticker-workbench-button` 与 `.page-turn-snapshot-action` 统一声明 `border-radius: 50px`；该规则当前仍存在，故本次问题不是圆角声明消失。
- **实施前复现**（本地 `127.0.0.1:5164`，桌面 `1470 × 802`）显示动画中两个 `.page-turn-snapshot-action` 计算尺寸约 `92 × 40px`、文案为“贴纸工作台”；常态真实按钮为 `153 × 45px`、带图标且文案为“前往贴纸工作台”。实施后桌面两者均为 `153 × 45px`，移动端均按页宽为 `123 × 45px`。
- **实施前测试事实**：`src/features/journal/PageTurnSheet.test.tsx` 只断言快照动作数量和“贴纸工作台”文本；实施后已增加完整文案、图标标记和无障碍隐藏属性断言。

## 4. 目标与非目标

### 4.1 目标

- 翻页快照动作使用与常态按钮相同的“前往贴纸工作台”文案。
- 翻页快照动作包含与常态按钮语义一致的 Sticker 图标视觉，占位和间距与共享按钮对齐。
- 常态和动画态保持相同的胶囊圆角、最小高度、边框、背景、阴影和主要水平内边距，避免结构替换造成宽度跳变。
- 增加自动回归断言，防止快照再次退化为短文案或无图标的纯文字块。

### 4.2 非目标

- 不改变按钮点击行为、禁用条件、目标日期、贴纸放置流程或无障碍交互语义。
- 不把动画快照变成可点击控件，不把 React 真实按钮交给 `page-flip` 管理。
- 不调整翻页方向、时长、折页几何、动态阴影、page-flip 版本或 Canvas/WebGL 数量。
- 不修改持久化数据、IndexedDB schema、产品范围或场景颜色/工具栈等当前工作树中的其他改动。

## 5. 方案说明

在 `PageTurnSheet` 中把快照动作从单一文本 `div` 改为结构化的只读动作元素：包含 Sticker 图标的 SVG 标记、完整文案“前往贴纸工作台”和与真实按钮一致的 class/布局字段。图标只作为视觉快照，不增加交互；其路径使用当前 `lucide-react` `Sticker` 图标的既有几何，避免引入新的图标库或第二套资源。

在 `src/styles.css` 中为快照动作补齐与真实按钮一致的 `display`、`gap`、`padding`、`min-height` 和文字布局；保留现有 `50px` 胶囊圆角，并让共享视觉合同集中在日记按钮和快照替身的选择器上。若需要图标尺寸规则，使用快照专属子类，不改全局 `dd-button` 或其他按钮。
