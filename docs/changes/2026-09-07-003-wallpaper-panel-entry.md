## 1. 给阅读者的结论

墙纸不再拥有独立的右上角入口，而是复用现有场景配色入口。面板保留两个 tab，从左到右为“书桌 / 墙纸”；墙纸 tab 使用原墙面纯色卡片和 Candy Cloud 图集预览卡片，点击卡片立即切换房间墙纸。

## 2. 用户需求

- 删除刚实现的独立墙纸入口。
- 统一使用原场景配色入口。
- 两个 tab 为“书桌 / 墙纸”。
- 墙纸使用预览卡片，不再使用文字列表 select。
- Candy Cloud 卡片使用 `public/assets/wallpapers/candy-cloud-cube-net.png`；默认墙面使用纯色卡片。

## 3. 当前源码事实

- `src/app/App.tsx` 当前同时挂载场景配色入口与独立墙纸入口。
- 场景配色面板已有颜色/预设 tab 与卡片布局。
- 墙纸主题仍由 `src/domain/wallpaper-theme.ts` 定义并通过 `localStorage` 持久化。

## 4. 目标与非目标

### 4.1 目标

- 复用现有配色入口、面板展开状态和按钮位置。
- 将 tab 文案改为“书桌 / 墙纸”。
- 用可访问的预览卡片选择 plain/Candy Cloud。

### 4.2 非目标

- 不改变墙纸纹理、五面 cube-net 映射或墙体模型。
- 不改变场景颜色状态、预设存储和墙纸 localStorage key。
- 不新增第三方 UI 依赖。

## 5. 方案说明

移除 `OpenSettingsPanel.wallpaper` 和独立 `<select>`，把墙纸选项作为现有设置面板的第二个 tab 内容。预览卡片使用按钮语义，卡片内部显示纯色块或 atlas 图片，当前项通过 `aria-pressed` 和视觉边框表示。

## 6. 预计改动与影响评估

- 修改 `src/app/App.tsx`：移除独立入口，调整 tab 文案并加入墙纸卡片。
- 修改 `src/styles.css`：复用/补充墙纸预览卡片样式，适配窄屏。
- 修改 `src/app/App.test.tsx`：验证单一入口、两个 tab 和卡片选择。
- 更新 `docs/product/mvp.md` 与架构/变更记录，保持文档与源码一致。

### 6.1 核心数据结构变化

### 6.2 上下游与跨模块影响
