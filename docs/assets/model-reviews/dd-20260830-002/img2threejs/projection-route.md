# 投影纹理路线判定

判定：**跳过 reference projection，采用程序化、可重照明的独立 PBR 通道**。

原因：参考图中的墙漆、木地板和暖白涂漆木没有必须逐像素复刻的徽标、图案或独特污损；七张图还包含互不一致的生成式照明。把其中一张图投影到近 360° 房间会烘焙窗光、在墙角产生接缝，并让相反视角失去依据。用户明确要求新增模型的纹理效果，因此使用确定性程序纹理更符合运行时多机位和光照需求。

实施约束：

- wall/floor/painted-wood 分别生成独立 albedo、roughness、height 与 AO 证据；不复用 albedo 充当数据图。
- 玻璃使用参数化 MeshPhysicalMaterial，不从参考图裁切天空。
- 程序纹理只匹配参考的色域、方向、频率和粗糙度层次，明确属于近似而非像素级复刻。
