# 参考图适用性判定

判定：**conditional / 可继续**。

通用 rubric 将普通“场景照片”列为 reject；本集合可以继续的原因是：画面中只有一个明确目标——无陈设的建筑壳体组件，且用户要求的是程序化静态环境而非精确网格提取。七张视图共同给出矩形拓扑、四面墙、唯一窗墙、窗框分件和相反墙角，隐藏面风险显著低于单张场景图。

条件与硬边界：

1. 不声称从图片获得工程尺寸；所有数值都要标为源码约束或设计推断。
2. 生成视图冲突时按“源码空间关系 > 主/反透视 > 顶视拓扑 > 单墙立面画幅”排序。
3. 不创建门、家具、天花板或室外场景。
4. 材质使用可重照明的程序化独立 PBR 通道，不投影生成图中的烘焙光影。
5. 验收必须覆盖主视角、相反视角、侧向视角和地板/窗框近景；仅一张正面截图不能证明近 360° 成立。
