# 房间壳参考图分析

## 结论与证据范围

- 目标：一个无家具的矩形建筑壳体组件，而不是从照片提取网格。实现目标是实时浏览器中的程序化 Three.js 静态环境。
- 参考集合：`00` 主三分之四透视、`01` 顶视、`02` 西侧窗户墙立面、`03` 北墙立面、`04` 东墙立面、`05` 南墙立面、`06` 相反墙角透视。
- 权威优先级：当前源码尺寸/机位负责现有桌子空间关系；`00` 与 `06` 负责总体外观和材质；`01` 只负责矩形拓扑与单窗墙；`02` 负责窗框分件和高宽比；`03`–`05` 负责三面墙无开口。
- 生成图不是测量图。房间长宽高、墙厚、窗户沿墙位置、窗台高度均需在规格中写成可审查的设计推断。

## Layer 1：识别与分类

- `primaryDomain`: `object`。
- 类型：静态建筑壳体 / hard-surface architectural assembly。
- 结构：四面墙、连续地板、西墙窗洞、踢脚线、窗框、窗台、横竖梃与玻璃组成的 compound layered shell。
- 识别置信度：0.98；精确比例置信度：0.58。

## Layer 2：总体形体与轮廓

- 矩形平面，双轴对称的基础包围体；唯一非对称特征为西墙窗洞。
- 主要体量可由正交平面、窄长方体、窗洞周围四块分段墙板和薄玻璃平面构成。
- 参考没有给出真实尺度。实现以现有桌子宽 `12`、深 `8` 和桌腿最低点为尺度锚点，保留桌侧、桌后和桌前环绕余量。

## Layer 3：宏观—中观—微观分解

### Macro

1. 房间根节点。
2. 地板总成。
3. 北/东/南三面空白墙。
4. 西侧窗户墙总成。

### Meso

1. 地板承载层与重复木板系统。
2. 四面墙的内表面和四段踢脚线。
3. 西墙窗洞的上、下、前、后墙板。
4. 窗外浅色背板、四块玻璃、外框、内框、窗台、竖梃和横梃。

### Micro / surface groups

1. 木板之间的真实缝隙和逐板轻微色差。
2. 木纹的宏观流向、中频纹路与微小孔隙高度。
3. 墙漆低频色值起伏、细粒高度和粗糙度变化。
4. 窗框涂漆木的细微纵向纹理与较低粗糙度边缘响应。
5. 踢脚线的顶部收边和墙—地接触阴影。

## Layer 4：空间关系

- `<floor, supports, desk legs>`：地板顶面位于现有四条桌腿最低点下方的极小间隙，桌子根节点保持 `[0,0,0]`。
- `<north/east/south/west walls, bound, floor>`：墙底与地板顶面齐平，墙面法线朝向室内。
- `<west wall panels, surround, window opening>`：四块墙板围成真实开口。
- `<window frame, overlaps, opening edges>`：外框轻微嵌入墙洞并向室内凸出。
- `<glass panes, inset-in, frame>`：四块玻璃位于框体外侧，避免与横竖梃共面闪烁。
- `<baseboards, flush-with, wall bottoms>`：踢脚线贴墙并轻微向室内凸出。

## Layer 5：PBR 材质观察

- 墙漆：介电、哑光；灰鼠尾草绿低饱和 albedo，roughness 约 0.88–0.96，微弱 height/normal，metalness 0。
- 木地板：介电、暖中值棕；roughness 约 0.56–0.72，窄长木纹 height，逐板色差和接缝 AO；不把照明高光烘进 albedo。
- 窗框与踢脚线：暖白涂漆木，satin finish，roughness 约 0.48–0.64，微弱纵向纹理，metalness 0。
- 玻璃：低粗糙度透明介质；为了实时稳定只使用克制透明/反射，不声称还原真实折射或室外景物。
- 各 PBR 通道必须独立生成；albedo 使用 sRGB，roughness/height/AO 保持线性数据纹理。

## Layer 6：色彩与表面

- 墙：低饱和灰绿色，值域中等；产品运行时墙色应与当前背景配置保持同一色族，但不冒充现有可编辑背景字段。
- 地板：暖棕色，从暗棕缝隙到中亮棕纹理；饱和度低于桌面胡桃木，避免抢焦。
- 窗框/踢脚线：暖灰白；玻璃/窗外背板为低饱和淡蓝灰。

## Layer 7：身份特征

1. 唯一窗户只在西墙。
2. 窗户为高窄四格形式，单根竖梃和单根横梃。
3. 三面墙完全无开口、无门、无装饰。
4. 连续暖木长板地面与浅色踢脚线。
5. 主视图与反向视图中窗户从画面左侧切换到右侧，验证其真实空间位置。

## Layer 8：不确定性和冲突

- `01` 顶视图包含轻微立体透视，不可当作精确正交测量。
- `02` 立面把窗户视觉上居中；透视图对沿墙位置约束较弱。规格采用“西墙沿深度略偏北”的设计推断并标低置信度。
- 空白墙立面画幅不同，不能用像素宽度推导相对墙长。
- 参考没有桌子，房间与桌子的所有间距以源码模型包围盒和现有镜头轨迹为权威。
- 参考显示天花板边缘，但用户要求只保留窗户、墙和地板；运行模型不创建天花板。
- 室外几何、真实玻璃厚度、墙体建筑厚度均未定义；实现只提供足以支撑室内视图的程序化近似。
