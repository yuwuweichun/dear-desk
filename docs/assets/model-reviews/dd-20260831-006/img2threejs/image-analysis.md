# 参考图分析：书房壳体细化

- 目标是建筑室内壳体，`primaryDomain=object`；可见宏观部件为墙面、地板、踢脚线和西墙窗户。
- 墙面是低饱和灰绿色、粗糙度较高的涂料/石膏表面；细节是低对比颗粒和微弱起伏，不是高频装饰图案。
- 地板是深暖棕色木材，窄长板沿房间纵深连续排列；板缝细、低对比，木纹沿板长方向延伸，局部有轻微色差与结疤变化。
- 窗户由真实墙洞、暖白外框、中央水平/垂直分格、四块透明/半透明玻璃和向室内突出的窗台组成。窗台是可见的结构特征，不能只用玻璃平面替代。
- 踢脚线位于墙地交界，主板为暖白色，上沿存在较窄的压条/阴影层次。
- 单张透视图不提供窗户背面、户外景观和墙体厚度的可靠证据；这些区域继续以低风险建筑壳体近似，不声称精确复原。

## 本轮实现映射

- 首轮真实截图暴露出近黑墙面、整块酒红地板、过薄踢脚线和窗户构图残缺四项偏差，因此第二轮从比例与材质连接重新校正。
- 窗洞宽 `10.3`、高 `12.65`、中心 `z=-7.8`；`sillDepth=1.05`、`sillHeight=0.22`、`sillOverhang=0.68`，并增加窗台下裙板。
- `baseboard.height=0.94`、`depth=0.26`、`capHeight=0.12` 与 `capInset=0.18` 映射参考图中较高、带顶部层级的米色踢脚线。
- 地板使用 38 个浅盒实例与暗色底层形成真实板缝，独立 SRGB albedo 与 NoColorSpace roughness/bump/AO 程序化生成纵向 grain、波纹、结疤和板间色差。
- 墙面基础采样约为 `rgb(137,146,126)`，使用白色材质承载贴图，避免首轮贴图与材质颜色二次相乘导致近黑。

## 第二轮视觉结论

- 同尺寸对照：`room-comparison-final.png`；反向结构图：`room-render-opposite.png`。
- 分层评分：构图 `0.82`、结构 `0.82`、材质 `0.76`、光照 `0.70`。
- 仍保留的差异：参考图的墙面是更丰富的照片级微斑驳；木地板有更强的结疤、宽幅窗光高光；窗外是自然景深散景，而当前实现是低频程序化绿景。
- 自动 silhouette IoU 为 `0.733`，但该工具将铺满画面的室内场景当作孤立物体分割并提示背景不明确，因此只作为保留的风险信号，不替代同尺寸和部件级审查。
