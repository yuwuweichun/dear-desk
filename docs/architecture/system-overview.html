Dear Desk · 当前事实架构

本地记录与贴纸，投影成双页日记和单活跃 WebGL 桌面

Dear Desk 是纯前端、本地优先的单页应用。IndexedDB v3 保存文字、贴纸 source、Forge PNG 与两种表面的位置；Zustand 协调本子开合、双页游标、仿真翻页和贴纸工作流；DOM 承担可读页面与表单，R3F 只负责需要空间关系的桌面和本子外形。

当前事实

本子聚焦开合、独立 Sticker Forge 工作台、图片本地抠图、桌面/日记双目标、双页仿真翻页，以及左页留白、右页单日期、历史正文可编辑的阅读/书写流程都已有源码。DD-20260809-004 的 lint、33 个自动测试与生产构建已通过；当前执行环境未提供 ego-browser，桌面、移动和本地 HTML 视觉交互仍待用户手动验收，不能从源码存在反推为已验收。

01 · 心智模型

事实、协调、投影和瞬时动画必须分开

系统没有服务端。用户显式保存后，浏览器当前 origin 下的 IndexedDB 是持久化事实；页面内的 Zustand store 是运行期协调层；DOM、R3F 和 Sticker Forge 是消费者或临时视觉生产者。纸张翻动角度、Three.js Mesh、对象 URL 和 worker 都不是业务数据。

01用户意图记录、翻页、制作、放置
02应用动作Zustand 锁定合法状态变化
03领域与仓储校验、查询、事务写入
04IndexedDB v3保存当前浏览器事实
05视觉投影DOM、R3F 或 Forge

说明数据边界； 说明渲染边界； 说明历史浏览不等于修改当天业务日期。

02 · 运行时

React 组合一个 store，并保证 WebGL Canvas 单活跃

src/main.tsx 创建两个 Dexie repository 和一个 Zustand store。App 根据 stickerWorkflow 切换桌面与制作器：composing 时卸载 R3F，再让 Sticker Forge 创建自己的 Canvas；其他阶段由 DeskScene 持有唯一 R3F Canvas。双页日记始终是 Canvas 的 DOM sibling。

当前运行时层级
main.tsx
└── AppStoreProvider
    └── App
        ├── stickerWorkflow === 'composing'
        │   └── StickerStudio -> one Sticker Forge Canvas
        └── otherwise
            ├── DeskScene -> one R3F Canvas
            │   ├── CameraRig + desk + NotebookObject
            │   └── StickerObject[] for desk surface
            ├── JournalPanel -> DOM double-page book
            │   ├── BlankJournalPage -> previous-page intent
            │   ├── JournalReadingPage -> current right-page text + stickers
            │   ├── one vertical reading/editing slider + writing action
            │   └── PageTurnSheet -> CSS 3D animation
            └── StickerControls
CSS 3D 不是第二个 WebGL renderer

PageTurnSheet 只使用 DOM 的 perspective、rotateY、正反面和阴影。它没有 Three.js scene、Canvas 或持久化物理状态；reduced-motion 下改为短淡出。

03 · 双页日记

日期索引确定右页，局部会话再控制阅读、书写与保存

  1. 加载今天App 调用 loadToday() 和 loadStickers()，保持桌面摘要、当天编辑和贴纸目标兼容。
  2. 打开本子3D 命中区或 DOM 按钮把 NotebookPhase 推进到 editing；JournalPanel 此时挂载，并以 reading + idle 开始。
  3. 建立页序loadJournalPages() 并行读取 DailyEntryRepository.listDates() 与 StickerRepository.listJournalDates()，合并今天、去重、排序并丢弃未来日期。
  4. 按需读取首次读取当前右页和相邻上一日期的正文与贴纸 Blob；页序查询本身只读取日期/instance 字段，不加载全部历史 PNG。
  5. 呈现当前日期journalCursor 只代表右页日期。左页不显示日期、正文或贴纸，只保留上一页命中；右页统一投影今天或历史正文与贴纸。
  6. 进入书写外置的单个竖向滑动按钮按“阅 / 读 / 编 / 辑”自上而下显示，选中块随 journalMode 上下移动；切到编辑只进入准备态。其下方动作按钮按“图标 / 书 / 写”竖排，被点击后 JournalBook 才以当前右页正文初始化 draftDate 与 draft，切换为 textarea 并聚焦；书写阶段动作变为“图标 / 收 / 笔”。
  7. 按页保存“收笔”调用 saveJournalEntry(rightDate, draft)。repository 仍按显式日期写入；store 更新 journalPageEntries[date]，仅当日期是今天时同步 entry 别名。
  8. 保护草稿正文有改动时，翻页、切回阅读和关闭只显示“请先收笔”，不会提交游标、关闭本子或自动写库；保存失败继续保留 textarea 与草稿。
  9. 请求翻页空白左页调用 requestJournalTurn('previous')，右页窄页缘调用 requestJournalTurn('next')。书写中由组件拦截；边界或 store 非 idle 请求返回 false。
  10. 预读并提交store 补齐目标右页缺少的正文和贴纸，再把阶段从 loading 切到 turning；PageTurnSheet 动画结束后调用 settleJournalTurn() 原子提交游标。
  11. 保持今天selectedDate 始终是今天，仍只决定贴纸工作台“放到日记”的目标；历史正文可编辑不会改变该贴纸 placement 语义。
翻页状态协议
idle
  -> requestJournalTurn(direction)
  -> loading: read target right page and previous neighbor if cache misses
  -> turning: render PageTurnSheet and lock new intents
  -> CSS animationend
  -> settleJournalTurn()
  -> commit journalCursor
  -> idle
局部阅读与书写协议
reading + idle
  -> editing + idle
  -> editing + writing (draftDate = current rightDate)
  -> editing + saving
  -> saveJournalEntry(rightDate, draft)
  -> editing + idle (success) | editing + writing (failure)

04 · 贴纸

制作器独立于日记草稿，结果可以落到桌面或今天

桌面“贴纸工作台”进入 composing 后，StickerStudio 支持文字、PNG/JPEG/WebP、矩形保留、本地 U-2-Netp 自动抠图和 Canvas 2D 手动修整。Sticker Forge 仍只负责公开 source 的轮廓、材质、peel 预览与 flat PNG 捕获。

贴纸调用方向
App.openStickerStudio()
  -> App unmounts DeskScene
  -> StickerStudio + optional local cutout worker
  -> fixed Sticker Forge session
  -> transparent flat PNG + confirmed source PNG
  -> prepareStickerPlacement(draft, 'desk' | 'journal')
  -> one Dexie transaction writes source/definition/render/instance
  -> desk: StickerObject (R3F)
  -> journal: JournalStickerLayer (DOM, selectedDate = today)

日记历史贴纸只投影，不允许选择或拖动；历史正文则通过统一的“编辑 → 书写 → 收笔”流程修改。今天页继续支持贴纸放置、移动、15° 旋转和删除。右页下一页命中缩到页缘，避免覆盖正文选择和 textarea。

06 · 数据

IndexedDB v3 分离正文、图片 source、渲染资产和 placement

数据库名为 dear-desk。v3 保留 dailyEntries，新增图片 source 表，并让实例使用 desk | journal 判别联合；日记实例通过 [surface+journalDate] 索引按日期查询。阅读/书写改造只增加 saveJournalEntry(date, text) 应用 action 和局部界面状态，没有升级 schema，也不持久化阅读模式、游标或草稿。

IndexedDB v3 schema
database.version(3).stores({
  dailyEntries: 'date, updatedAt',
  stickerDefinitions: 'id, kind, createdAt',
  stickerInstances: 'id, surface, [surface+journalDate], definitionId, updatedAt',
  stickerRenderAssets: 'id, upstreamCommit',
  stickerSourceAssets: 'id, createdAt'
})

同时是正文主键和日记贴纸关联键； 让 DOM 与 R3F 可以从同一 PNG 事实重建视觉。清除站点数据、换浏览器或换设备会失去这些内容，这是当前边界。

07 · 渲染

R3F 给出空间本子，DOM 给出可读双页

NotebookObject 用透明命中几何发出打开意图，用封面铰链和程序化布面/纸芯几何表现打开后的双页轮廓；它不读取正文或 Blob。RoundedBox 和 scene-visuals 只提供可释放的圆角几何、角色色与程序纹理，不拥有业务状态。JournalPanel 对齐聚焦后的本子，提供空白左页、统一右页、局部模式控件、按日期 textarea 和纸页贴纸。

JournalStickerLayer 的坐标是纸页内 0..1 归一化值。今天页保留 pointer capture、预览位置和 pointer up 提交；历史页即使进入正文书写也只复用 PNG 投影并关闭贴纸 pointer events。桌面 StickerObject 仍创建对象 URL 和 Three.js Texture，并在卸载时释放两者。

为什么正文不进入 WebGL

textarea、键盘焦点、选择文本、错误反馈和屏幕阅读器语义都更适合 DOM。只有相机、光照、遮挡和桌面空间坐标进入 R3F；仿真翻页的视觉价值不需要牺牲表单质量。

08 · 失败路径

加载、翻页、保存和制作失败都保留上一份可靠事实

失败点当前行为保留内容
今天读取失败loadStatus: error，显示本地记录不可用数据库不被改写
历史日期索引或可见页读取失败journalLoadStatus: error，双页显示可见错误今天正文和贴纸链路仍独立
目标页预读失败翻页从 loading 复位到 idle，不提交游标原跨页保持不变
快速重复点击非 idle 请求返回 false只有一个 pending cursor
dirty 书写时翻页、切回阅读或关闭意图被组件拦截，live status 提示先收笔当前右页、模式与局部草稿
空文本、超长或任意日期写入失败禁用/拒绝收笔并显示错误，恢复 writingJournalBook 的 draftDate 与草稿
贴纸创建事务失败不加入内存集合并显示错误不会留下部分 source/definition/render/instance
贴纸移动提交失败显示错误并重新加载持久化位置最后一次成功位置
WebGL 初始化失败显示 DOM 降级入口双页 DOM 与 IndexedDB 日记链路
reduced-motion纸张大角度旋转改为 120ms 淡出相同游标提交和边界语义

09 · 示例

正文页、贴纸-only 页和今天怎样组成一本本子

假设 IndexedDB 中有 8 月 5 日正文、8 月 7 日只有一张日记贴纸，而今天是 8 月 9 日且尚未保存。日期查询合并后得到三个页面，不生成 8 月 6 日或 8 月 8 日的无限空白纸。

页面序列与一次向前翻
journalPageDates = [2026-08-05, 2026-08-07, 2026-08-09]

open (reading):
  left  = blank (previous-page hit target -> 2026-08-07)
  right = 2026-08-09 (today text + stickers)

click left:
  preload 2026-08-05
  animate left sheet toward right
  settle cursor

result:
  left  = blank (previous-page hit target -> 2026-08-05)
  right = 2026-08-07 (sticker-only, right edge -> next)

edit historical text:
  click 编辑 -> 书写 -> textarea for 2026-08-07
  click 收笔 -> saveJournalEntry('2026-08-07', draft)

顶层编辑模式可以跨翻页保持，但每个日期都必须再次点击“书写”才创建该页草稿。只有“收笔”成功才写 dailyEntries；dirty 草稿会阻止关闭，页面刷新仍不提供草稿恢复。关闭并重新打开后，阅读游标和模式回到今天的阅读态。
